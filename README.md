# 태엽 밖으로 · Beyond the Clockwork

모두가 행복하도록 만들어진 장난감 마을에서, 고장 나 버려진 인형 F2가 마을의 진상을 파악하고 자유를 찾아 싸우는 픽셀 아트 2D 탑다운 액션 로그라이트입니다. 브라우저에서 바로 실행되며, 외부 게임 프레임워크 없이 ES modules와 Canvas로 만들었습니다.

불량 판정서 타이틀 → 폐기장 튜토리얼 → 웃음 마을과 모루 → 1장 웃음거리(브라스) → 2장 무음공장(프레스) → 3장 중앙시계탑(오르덴) → 주민 해방 엔딩까지 플레이할 수 있습니다. 공개 주소는 https://beyondtheclockwork.mungaeng.workers.dev 이고, `main`에 푸시하면 자동 배포됩니다(`DEPLOY.md`).

## 실행

Node.js 20 이상이 필요합니다. 게임 실행에는 패키지 설치가 필요 없습니다.

```powershell
npm.cmd start
```

브라우저에서 **http://localhost:4173** 을 엽니다. `index.html`을 파일로 직접 열면 JSON을 불러올 수 없으므로 로컬 서버로 실행하세요. 다른 포트는 `$env:PORT=4174`로 지정합니다.

```powershell
npm.cmd run check      # 데이터 일치, 아트 검사, 자동 테스트
npm.cmd run playtest   # 입력만 쓰는 봇으로 영구 강화 없이 12구간 완주 검사
npm.cmd run data:sync  # 기획 원본 수정 후 런타임 데이터 재생성
```

## 조작

| 행동 | 키보드·마우스 | 패드 |
| --- | --- | --- |
| 이동 / 조준 | WASD / 마우스 | 왼쪽 / 오른쪽 스틱 |
| 태엽 렌치 3연타 | 좌클릭 유지 | RB 유지 |
| 회피 | Space | B |
| 첫 번째 속성 기술 | Q / E | X / Y |
| 두 번째 속성 기술 | R / F | LB / LT |
| 융합 | 우클릭 | RT |
| 말 걸기·상호작용 | G | A |
| 지도 / 도감 / 설정·일시정지 | M / Tab / Esc | View / - / Menu |

표는 기본 '키보드로 걷기' 기준입니다. 처음 깨어난 뒤 키보드·마우스·방향키 가운데 조작 방식을 고르고, 설정의 조작 키 탭에서 바꾸거나 키를 다시 정할 수 있습니다. 대화는 Space·Enter·클릭으로 넘기고 Esc로 건너뜁니다. `F9`는 원하는 구간으로 이동하는 디버그 메뉴입니다. 휴대폰은 가로로 놓고 왼쪽을 끌어 이동, 오른쪽 버튼으로 싸우며, 공격은 가까운 적을 자동으로 조준합니다.

## 현재 구현 범위

- **이야기:** 판정서 도장 연출, 눈뜨는 오프닝, 모루·볼트·나사 대화, 첫 종소리 이벤트, 보스마다 만남·풀어 준 뒤 대사, 장마다 끝 장면, 시계탑 붕괴와 주민 해방 엔딩. 3장 어려움을 처음 깨면 히든 엔딩이 한 번 나옵니다. 멈춤 창의 수리 장부에서 장 인장·마주한 보스·설계도를 보고, 마을에서는 본 보스 이야기를 다시 볼 수 있습니다.
- **마을:** 걸어 다니는 웃음 마을(주민 19명)과 야시장, 일정 시간마다 울리는 종. 주민에게 말을 걸면 생김새와 이야기 단계에 따라 다른 말을 하고, 장을 깰수록 종소리에 중얼거리는 주민이 늘며, 해방 뒤에는 종이 멈추고 수리점 앞에 고칠 물건을 든 주민이 줄을 섭니다. 2장 쉼터에는 쉬는 공장 일꾼들.
- **원정:** 1장 웃음거리 12구간(로코, 야시장 쉼터, 브라스), 2장 무음공장 12구간(아이리스, 불량품 보관창고 쉼터, 프레스), 3장 중앙시계탑 11구간(틱·톡, 벨가드, 오르덴 두 번). 방마다 두 그림 중 하나, 웨이브 모양과 몹 조합은 원정마다 새로 뽑고, 방 장애물과 정예 방이 있습니다. 1·2장은 쉬움·보통·어려움, 3장은 보통·어려움입니다.
- **전투:** 렌치 3연타, 회피, 축전, 8속성(불·얼음·전기·바람·소리·물·빛·자력) 각 기술 2개, 융합 28종, 상태이상 8종, 보스마다 파훼 과제.
- **속성 선택:** 원정 전 모루에게 2개 장착, 뒷마당 허수아비에게 시험(뒷마당의 모루에게서 바로 바꿔 끼울 수 있음).
- **성장:** 모루의 조율판 12개 능력(장마다 10단계씩, 최대 30단계), 한 단계·전체 무료 환급, 원정 보상 카드(일반·희귀·전설), 렌치·기술 개조, 속성 특성, 동전 상점, 나사의 원정 기름.
- **저장:** 브라우저 자동 저장, 기기 이동 코드·자동 동기화(Cloudflare), 손상된 저장 보존. 플레이 통계와 관리자 페이지(`admin.html`).
- **편의:** 체력 바 아래 F2에게 걸린 효과 표시(기름·특성·시간제 효과), 조율판·출발 창 첫 안내, 숫자 키로 보상·출발·상점 고르기, 결과 창의 '바로 다시 출발', 키 재지정, 효과음·배경음악 크기, 동작·섬광 줄이기, 피해 숫자, 전체화면, 속성 도감(속성별 융합 칩, 상태 설명).

## 폴더 구조

```text
docs/design/clockwork-design.v1.json  정식 기획 원본(피해·HP·가격·시간)
docs/                                 기획 문서, 장별 계획, 게임 데이터 표, 업데이트 전체 기록
src/data/                             combat·progression(생성), slice·maps·dialogue(직접 수정)
src/engine/                           화면과 브라우저에 의존하지 않는 게임 규칙(game.js가 중심)
src/render/                           게임 화면 그리기, 이펙트 그림 목록, 맵 불러오기
src/animation/                        플레이어, 몹, NPC, 시전 이펙트 애니메이션
src/ui/  src/main.js                  타이틀·대화창, 입력·패널·저장소·오디오 연결
src/audio/                            효과음(코드 합성·녹음)과 배경음악
scripts/                              데이터 생성·검사, 아트 빌드, 균형 측정, 지도 편집기(/scripts/map-editor/)
art/                                  스프라이트, 맵 배경, 이펙트, 소리
test/                                 자동 테스트
```

피해·HP·가격·시간을 바꾸려면 `docs/design/clockwork-design.v1.json`을 고친 뒤 `npm.cmd run data:sync`를 실행합니다. `combat.json`과 `progression.json`을 직접 고치면 `data:check`에서 잡힙니다. 엔진은 유닛 단위로 계산하고(1유닛 = 기준 픽셀 40), 60Hz 고정 시뮬레이션입니다.
