# 태엽 밖으로 · Beyond the Clockwork

폐기된 로봇이 마을의 진상 파악과 자유를 위해 전투를 진행하는 2D 탑다운 액션 로그라이트입니다. 브라우저에서 바로 실행되며, 외부 게임 프레임워크 없이 ES modules와 Canvas로 만들었습니다.

불량 판정서 타이틀 → 폐기장 튜토리얼 → 웃음 마을과 모루 → 웃음거리 12구간 → 브라스 격파 → 귀환·영구 조율·재도전까지 플레이할 수 있습니다.

## 실행

Node.js 20 이상이 필요합니다. 게임 실행에는 패키지 설치가 필요 없습니다.

```powershell
npm.cmd start
```

브라우저에서 **http://localhost:4173** 을 엽니다. `index.html`을 파일로 직접 열면 JSON을 불러올 수 없으므로 로컬 서버로 실행하세요. 다른 포트는 `$env:PORT=4174`로 지정합니다.

```powershell
npm.cmd run check      # 데이터 일치, 아트 검사, 자동 테스트
npm.cmd run playtest   # 입력만 쓰는 봇으로 영구 강화 없이 12구간 완주 검사
npm.cmd run data:sync  # 기획 원본 수정 후 런타임 데이터 재생성
```

## 조작

| 행동 | 키보드·마우스 | 패드 |

| 이동 / 조준 | WASD / 마우스 | 왼쪽 / 오른쪽 스틱 |

| 융합 | 우클릭 | RT |

대화는 Space·Enter·클릭으로 넘기고 Esc로 건너뜁니다. 보상은 마우스 또는 1·2·3으로 고릅니다. `F9`는 원하는 구간으로 이동하는 디버그 메뉴입니다. 휴대폰에서는 가로로 놓고, 왼쪽을 끌어 이동하며 오른쪽 버튼으로 싸웁니다. 공격은 가까운 적을 자동으로 조준합니다.

## 현재 구현 범위

- **이야기:** 판정서 도장 연출, 눈뜨는 오프닝, 독백, 모루·볼트 대화, 첫 종소리 이벤트.
- **튜토리얼:** 걷기, 공격, 회피, 전투를 직접 해 보면 넘어가는 폐기장 수업.
- **마을:** 걸어 다니는 웃음 마을과 야시장, 주민 NPC, 일정 시간마다 울리는 종.
- **원정:** 웃음거리 12구간. 일반 전투, 렌치 개조 보장 전투, 로코, 야시장 상점, 정예 전투, 브라스. 방을 비우면 1초 뒤 보상을 고르고 노란 표시로 걸어 나갑니다.
- **전투:** 렌치 3연타, 회피, 축전, 불·얼음·전기·바람 각 기술 2개, 융합 6종, 상태이상, 보스 제압과 통제축 풀기.
- **속성 선택:** 원정 전 모루에게 2개 선택, 뒷마당 허수아비에게 시험.
- **성장:** 모루의 조율판 13개 능력(각 20단계), 전체 무료 환급, 원정 보상, 렌치·기술 개조, 속성 교체, 동전 상점.
- **저장:** 브라우저 자동 저장, 저장 파일 내보내기·불러오기, 손상된 저장 보존.
- **편의:** 키 재지정, 효과음, 동작·섬광 줄이기, 피해 숫자, 전체화면.

## 폴더 구조

```text
docs/design/clockwork-design.v1.json  정식 기획 원본
docs/BeyondTheClockworkGameDesign.md  기획 문서
scripts/sync-data.mjs                 기획 원본에서 런타임 데이터 생성·검사
scripts/                              아트 가져오기, 클립 빌드, 검사 도구
src/data/combat.json                  생성 데이터: 전투·기술·융합·보스 수치
src/data/progression.json             생성 데이터: 성장·경제 수치
src/data/slice.json                   직접 수정: 적, 방, 보상, 조율 수치
src/data/maps.json                    직접 수정: 맵, 걷는 구역, 등장 위치, 포탈
src/data/dialogue.json                직접 수정: 대사
src/engine/                           화면과 브라우저에 의존하지 않는 게임 규칙
src/animation/                        플레이어, 몹, NPC, 시전 이펙트 애니메이션
src/render/canvas.js                  게임 화면 그리기
src/ui/                               타이틀과 대화창
src/main.js                           입력, 패널, 저장소, 오디오 연결
art/                                  스프라이트, 맵 배경, 시안
test/                                 자동 테스트
```

피해·HP·가격·시간을 바꾸려면 `docs/design/clockwork-design.v1.json`을 고친 뒤 `npm.cmd run data:sync`를 실행합니다. `combat.json`과 `progression.json`을 직접 고치면 `data:check`에서 잡힙니다.

엔진은 유닛 단위로 계산하고 1유닛은 기준 픽셀 40입니다. 60Hz 고정 시뮬레이션이라 화면 크기에 따라 전투 속도가 변하지 않습니다.

## 저장

저장은 브라우저 `localStorage`의 `beyond-the-clockwork.vertical-slice.v1`에 있습니다. `localhost`와 `127.0.0.1`은 서로 다른 저장 공간입니다.

## 업데이트

### 2026-11-03
- 배경음악 6곡을 256kbps에서 96kbps로 다시 인코딩(27.9MB → 7.2MB, 타이틀 2.4MB → 0.8MB). 타이틀 곡은 게임 로딩 중에 파일째 미리 받아 두고, 아직 받는 중이면 같은 파일을 두 번 받지 않고 기다렸다 재생합니다. 느린 회선 기준 첫 터치 후 재생: 로딩 5초 뒤 터치 0.4초, 2초 뒤 터치 1.9초.
- 타이틀을 벗어나면(새로 시작·도장 장면·폐기장 튜토리얼) 타이틀 곡이 0.25초 만에 꺼집니다.
- 첫 시작 배경음악 지연 수정: 효과음 45개와 다른 곡 5개가 타이틀 곡과 동시에 내려받아져 타이틀 곡이 늦게 준비되던 문제. 이제 타이틀 곡을 먼저 혼자 받고, 재생 준비가 되면 효과음·마을·거리 곡을 받습니다(느린 회선 기준 첫 터치 후 10초 → 0.1초).
- 그래픽 상향(B안, 조명 층): 맵 그림 속 등불을 자동으로 찾아 빛나게 하고, 시간대별 색감(웃음거리 앞길 낮 · 야시장과 브라스 광장 밤 · 야시장 이후 해 질 녘), 밤에는 어두운 화면에 등불·주인공 주변만 밝게, 캐릭터 발밑 그림자 진하게, 떠다니는 먼지·불씨 입자, 화면 가장자리 어둡게, 스킬 사용 시 속성 색 빛 번짐을 넣었습니다. "섬광·동작 효과 줄이기"를 켜면 입자와 깜빡임이 꺼집니다.
- 새 기술 개조 5장(작동 방식이 바뀌는 카드): 불꽃 궤적(과열 휘두르기 자리에 불길 3곳이 2초 남음), 배기 흔적(배기 폭발이 지나온 자리에서 터짐), 서리 파편(맞은 볼트가 파편 3개로 깨져 옆 적에게 튐), 지연 방전(도전 스패너가 3초 뒤 주변 전체 방전), 꿰뚫는 돌진(압축 돌진이 적을 꿰뚫고 뒤로 끌어당김). 한 원정에서 같은 기술의 개조는 1장만 고를 수 있습니다.
- 소리가 바로 나오지 않던 문제 수정: 효과음 파일과 타이틀·마을 음악을 게임 로딩 중에 미리 받아 두고, 첫 터치 때는 켜기만 합니다(느린 회선 기준 타이틀 음악 8.9초 → 0.4초). 앱을 나갔다 돌아오거나 정지 후 다시 켜면 음악과 효과음이 자동으로 다시 시작됩니다.
- 렌치 베기 이펙트를 E안(한 줄 초승달)으로 교체: 가는 호 하나가 머리(최대 3픽셀)에서 꼬리로 가늘어지며 지나가고, 1픽셀 그림자 선으로 밝은 바닥에서도 보입니다. 2타는 반대 방향, 3타는 조금 더 길게.
- 공격 모션 재생성(PixelLab): 1타·2타 남쪽(중간에 왼팔이 떨어져 보이던 문제), 2타 동쪽(얼굴이 이상하던 문제), 1타 남서쪽(왼팔이 사라지던 문제).
- 렌치 베기 이펙트 얇은 버전 시안 페이지를 만들었습니다: concepts/slash.html (실제 속도 반복 재생 포함).
- 보스 공격 효과음 확정: 로코 집게(철컥)·자석(낮은 종 웅)·흡입(짧은 휙)·과충전(금속판 쾅)·딱지(카드 착)·크레인(나무 상자 쿵), 브라스 지휘봉(칼집 스르륵)·행진(북 둥)·발구르기(묵직한 쿵)·나팔 파동(색소폰 빰)·돌진(색소폰 빠라밤)·병정 대열(나무 발소리)·카펫(천 펄럭). 후보 파일은 지우고 효과음 목록 E 그룹에 넣었습니다.
- 보스 공격 효과음: 로코 6개(집게·자석·흡입·과충전·딱지·크레인), 브라스 7개(지휘봉·행진·발구르기·나팔 파동·나팔 돌진·병정 대열·카펫) 공격마다 소리를 넣었습니다. 패턴마다 녹음 후보 2개를 만들어 효과음 목록 페이지 맨 위(H1·H2)에 올렸고, 게임에는 1번 후보가 들어 있습니다.
- 보스 맵도 들어오는 방향을 맞췄습니다: 로코 맵은 위쪽에서(로코와 13칸 이상 떨어진 곳), 브라스 광장은 남서쪽 아치 계단을 지나 아래쪽에서 걸어 들어옵니다.
- 출발 지점 맞추기: 앞 구간을 떠난 방향의 반대쪽에서 들어오도록 일반 전투 맵 9곳의 출발 지점과 들어오는 방향을 다시 정했습니다(예: 마을 남쪽 길로 나가면 첫 맵은 위쪽에서 들어옴, 동쪽 포탈로 나가면 다음 맵은 서쪽에서 들어옴). 출발 지점은 그 맵 출구에서 맵 폭의 절반 이상 떨어지게 했습니다. 로코·브라스 보스 맵과 야시장은 거리·볼트 위치 때문에 원래 출발 지점을 유지합니다.
- 맵 연결감: 새 구간에 들어가면 화면이 이동 방향으로 어둡게 쓸려 나가며 열리고, 주인공이 맵 가장자리(가장 가까운 끝)에서 출발 지점까지 걸어 들어옵니다. 걸어 들어오는 동안은 조작이 잠시 멈추고 적도 공격하지 않습니다.
- 광장 주민 30→24명(모든 종류 1명씩), 야시장 손님 12→8명으로 줄였습니다.
- 웃음 마을에서 원정을 떠나는 남쪽 출구의 "웃음거리로 ↓" 글자 표시를 없애고, 노란 포탈(고리와 화살표)을 놓았습니다. 포탈을 밟으면 바로 출발합니다.
- 휴대폰에서 전투 맵 배경음악이 안 나오던 문제 수정: 휴대폰은 화면을 누른 순간에만 음악을 시작할 수 있는데, 전투 음악은 포탈을 걸어서 지날 때 시작돼 막혔습니다. 첫 터치 때 모든 곡을 소리 없이 한 번 준비해 두도록 바꿨습니다.
- 보상 카드 등장 소리를 6번(맑은 확인음 0.3초)으로 정했습니다. 효과음 목록 페이지는 새 버전이 있으면 스스로 새로고침합니다.
- 보상 카드 등장 소리 후보를 0.3~0.5초짜리 짧은 소리 6개로 다시 만들었습니다. 게임에는 우선 1번(타악기 "짠" 0.3초)을 넣었습니다.
- 보상 획득 소리를 동전 짤랑 소리(RPG Audio handleCoins)로 바꿨습니다. 보상 카드 등장 소리는 짧은 팡파레 후보 5개를 효과음 목록 페이지 맨 위에 올렸고, 게임에는 우선 1번(색소폰 팡파레)을 넣었습니다.
- 포탈 이동 소리: 문 여는 소리 대신 공기가 빨려 들어가며 위로 솟는 "우웅" 소리와 부드럽게 올라가는 반짝 음 3개로 바꿨습니다.
- 효과음 다듬기: 태엽 쥐 자폭은 부드러운 "펑"(impactSoft), 팽이 회전은 바람 휙 소리(천 스침), 피격은 가벼운 금속 "팅"으로 교체. 비슷하게 깨지는 기계음처럼 들리던 정예 경비 충격파(금속 판 → 나무 쿵)와 오르골 발사(전자 뜯는 음 → 유리 "팅")도 바꾸고, 녹음 소리를 빠르게 돌려 어색하던 축전 가득·포탈·깜짝 상자·토끼는 원래 속도로 되돌렸습니다.
- 기계음 효과음 13개를 실제 녹음 소리로 교체: 축전 가득(종 딩), 체력 회복(피치카토), 구간 클리어(스틸드럼), 쓰러짐(가죽 떨어지는 소리), 깜짝 상자(금속 딸깍), 토끼 돌진(천 휙), 포탈(문 열림), 조율(금속 걸쇠), 웨이브 등장(발소리), 태엽 쥐 자폭(바위 부서짐), 나팔 사수(색소폰 한 음), 팽이(삐걱 회전), 로코 경보(종 땡). Digital Audio·Sci-fi 묶음 소리는 더 이상 쓰지 않습니다.
- 렌치 베기 이펙트를 A안(픽셀 스미어)으로 교체: 휘두르는 궤적을 시작·중간·끝 3장의 청록 쐐기로 끊어 보여 주고, 3타는 조금 더 넓게 + 앞쪽 충격파.
- 속성 부품 상점 가격을 모두 50 톱니로 통일했습니다(80/120/160 → 50). 첫 귀환 후 모루가 주는 첫 속성 부품은 그대로 무료입니다.
