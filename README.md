# 태엽 밖으로 · Beyond the Clockwork

폐기된 로봇이 마을의 진상 파악과 자유를 위해 전투를 진행하는 2D 탑다운 액션 로그라이트입니다. 브라우저에서 바로 실행되며, 외부 게임 프레임워크 없이 ES modules와 Canvas로 만들었습니다.

불량 판정서 타이틀 → 폐기장 튜토리얼 → 웃음 마을과 모루 → 웃음거리 12구간 → 브라스 격파 → 귀환·영구 조율·재도전까지 플레이할 수 있습니다.

## 실행

Node.js 20 이상이 필요합니다. 게임 실행에는 패키지 설치가 필요 없습니다.

```powershell
npm.cmd start
```

브라우저에서 **http://localhost:4173** 을 엽니다. `index.html`을 파일로 직접 열면 JSON을 불러올 수 없으므로 로컬 서버로 실행하세요. 다른 포트는 `$env:PORT=4174`로 지정합니다.

```powershell
npm.cmd run check      # 데이터 일치, 아트 검사, 자동 테스트
npm.cmd run playtest   # 입력만 쓰는 봇으로 영구 강화 없이 12구간 완주 검사
npm.cmd run data:sync  # 기획 원본 수정 후 런타임 데이터 재생성
```

## 현재 구현 범위

- **이야기:** 판정서 도장 연출, 눈뜨는 오프닝, 독백, 모루·볼트 대화, 첫 종소리 이벤트.
- **튜토리얼:** 걷기, 공격, 회피, 전투를 직접 해 보면 넘어가는 폐기장 수업.
- **마을:** 걸어 다니는 웃음 마을과 야시장, 주민 NPC, 일정 시간마다 울리는 종.
- **원정:** 웃음거리 12구간. 일반 전투, 렌치 개조 보장 전투, 로코, 야시장 상점, 정예 전투, 브라스. 방을 비우면 1초 뒤 보상을 고르고 노란 표시로 걸어 나갑니다.
- **전투:** 렌치 3연타, 회피, 축전, 불·얼음·전기·바람 각 기술 2개, 융합 6종, 상태이상, 보스 제압과 통제축 풀기.
- **속성 선택:** 원정 전 모루에게 2개 선택, 뒷마당 허수아비에게 시험.
- **성장:** 모루의 조율판 13개 능력(각 20단계), 전체 무료 환급, 원정 보상, 렌치·기술 개조, 속성 교체, 동전 상점.
- **저장:** 브라우저 자동 저장, 기기 이동 코드·자동 동기화(Cloudflare), 손상된 저장 보존.
- **편의:** 키 재지정, 효과음, 동작·섬광 줄이기, 피해 숫자, 전체화면.

피해·HP·가격·시간을 바꾸려면 `docs/design/clockwork-design.v1.json`을 고친 뒤 `npm.cmd run data:sync`를 실행합니다. `combat.json`과 `progression.json`을 직접 고치면 `data:check`에서 잡힙니다.

엔진은 유닛 단위로 계산하고 1유닛은 기준 픽셀 40입니다. 60Hz 고정 시뮬레이션이라 화면 크기에 따라 전투 속도가 변하지 않습니다.

## 저장

저장은 브라우저 `localStorage`의 `beyond-the-clockwork.vertical-slice.v1`에 있습니다. `localhost`와 `127.0.0.1`은 서로 다른 저장 공간입니다.
