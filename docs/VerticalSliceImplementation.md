# 18.1 구현 기록

기준: `BeyondTheClockworkGameDesign.md` v0.1 및 `clockwork-design.v1.json`의 `clockwork-design-0.1`.

## 책임 경계

`Game`은 브라우저 API를 호출하지 않습니다. JSON을 주입받고 `update(dt, input)`과 명시적 행동 메서드로 상태를 바꿉니다. `onSave(state)` 콜백으로 저장 경계를 알립니다. 상태 전체는 JSON 직렬화가 가능하며, 타이머는 일시정지되는 시뮬레이션 시각을 사용합니다.

렌더러는 상태를 읽어 화면만 그립니다. 렌더러의 공격 호·탄환·예고는 엔진의 판정값을 사용하고 피해를 직접 가하지 않습니다. DOM UI는 합법적인 게임 행동을 호출합니다. 성장 함수는 `progression.js`, 파일 검증·인코딩은 `storage.js`에 있습니다.

## 추가한 제작용 데이터

원본에 서술만 있던 판정 모양·투사체 속도·패턴 간격·일반 적의 구체 수치는 `src/data/slice.json`에 보관합니다. 새 아트 없이 전투를 검증하기 위해 캐릭터·배경을 Canvas에서 그렸습니다. 피해·가격·성장 수치를 UI나 렌더러에 복사해 전투 원본으로 사용하지 않습니다.

원정은 검증된 방 템플릿 3개와 작성된 경비 편성으로 생성합니다. 자유 타일 랜덤 생성과 진행 중 레이아웃 재생성은 사용하지 않습니다. 서비스 공간은 우선 상점, 두 번째 노드는 항상 전투로 구현했습니다.

## 확장 순서

1. 입력·전투 감각과 보스 예고에 대한 사람 플레이테스트, 아트 원본 크기·팔/렌치 애니메이션 개선.
2. 런타임 추출 범위 확장, 나머지 속성·융합의 판정 동작 및 전체 영구 성장 구현.
3. 사건·정비 공간, 나머지 지역·보스·인물 사건·엔딩·과조율을 기획 순서로 추가.

원본 8속성·28융합·12행의 개수와 가격 합계는 유지됩니다. 현재 수직 조각이 정식 범위 전체를 구현했다고 간주하지 않습니다.
