# 태엽 밖으로 — 상세 게임 기획서

문서 버전: 0.1 · 작성일: 2026-10-29  
영문 작업명: **Beyond the Clockwork**  
장르: 픽셀 아트 2D 탑다운 액션 로그라이트  
상태: 신규 콘셉트의 제작 기준 제안. 현재 Scriptfall 프로토타입에는 아직 적용하지 않았다.  
수치 원본: [기획용 JSON 데이터](design/clockwork-design.v1.json)

이 기획서는 기존 극장, 배우, 마왕 도피, 기억 초기화 설정을 대체한다. 주인공의 태엽 렌치, 짧은 도입, 행복한 장난감 마을의 통제라는 최신 방향을 기준으로 한다. 모든 피해·가격·시간 수치는 테스트 전 초기안이며, 참고 작품의 실제 수치를 복사한 값이 아니다.

## 1. 게임의 핵심

> 모두가 행복하도록 만들어진 마을.  
> 당신은 고장 나서, 자유로워졌다.

알록달록한 장난감 마을에서 스스로 생각하는 인형은 불량품으로 분류된다. 폐기장에서 깨어난 주인공은 수리용 태엽 렌치를 들고 중앙 시계탑으로 향한다. 매번 다른 부품과 속성을 조합하고, 쓰러지면 작은 수리점에서 다시 조립되어 도전을 이어 간다.

목표는 처음에는 마을 밖으로 나가는 것이고, 이후에는 주민들이 스스로 움직일 수 있도록 통제 신호를 끊는 것이다. 단순히 마을의 동력을 모두 끄는 것과 주민을 자유롭게 하는 일은 다르다.

### 1.1 플레이 약속

- 설명은 시작 화면의 세 문장으로 끝낸다. 첫 적과의 전투까지 20초 이내를 목표로 한다.
- 기본 공격과 회피만으로도 적의 예고를 읽고 싸울 수 있다. 스탯을 먼저 채워야 조작이 성립하는 구조는 피한다.
- 하나의 원정에서 네 구역과 최종 보스까지 도달할 수 있다. 실패하면 다음 원정은 첫 구역에서 다시 시작한다.
- 반복하면서 기본 스탯과 속성 특성을 영구 강화하되, 그 원정의 강한 빌드는 현장에서 완성한다.
- 밝은 마을을 처음부터 공포 폐허로 만들지 않는다. 같은 귀여운 물건이 통제 장치로 보이기 시작하는 변화가 핵심이다.

### 1.2 정식 범위

| 항목      | 범위                                                                |
| --------- | ------------------------------------------------------------------- |
| 플레이어  | 장난감 인형 1명, 이름과 성별은 후속 아트 단계에서 확정              |
| 기본 무기 | 태엽 렌치 1종, 3연타 기본 공격                                      |
| 속성      | 불·얼음·전기·바람·대지·물·빛·어둠 8종                               |
| 속성 기술 | 속성마다 2개, 총 16개                                               |
| 융합 기술 | 서로 다른 두 속성의 무순서 조합 28개                                |
| 동시 사용 | 속성 2종의 기본 기술 4개 + 해당 융합 1개                            |

| 첫 엔딩   | 영구 성장 최대치 이전에 가능. 숙련자는 무강화 완주도 가능해야 함    |

## 2. 참고한 성장 구조와 이 게임의 적용

하데스는 원정에서 잃는 은혜·동전과 거점에서 투자하는 영구 성장을 구분하고, 거울의 생존·기동·체력 같은 특성과 귀환 후의 대화로 다음 도전을 이어 준다. 이 구분과 실패 후에도 선택할 일이 생기는 흐름을 참고한다. [PlayStation 공식 하데스 가이드](https://www.playstation.com/en-us/games/hades/tips-and-tricks-to-survive-your-first-hades-encounters/)

영구 성장, 임시 부품, 거점 인물의 사건을 함께 배치하고 콘텐츠를 단계적으로 소개하는 접근도 참고한다. 하데스 개발사의 초기 업데이트에서 성장 기능과 인물 등장 조건을 조절하고 여러 귀환 대사를 추가한 사례를 확인했다. 해당 문서는 초기 개발 기록이므로 현재판의 정확한 비용·밸런스 근거로 사용하지 않는다. [Supergiant 공식 개발 기록](https://www.supergiantgames.com/blog/hades-welcome-to-hell-update-patch-notes/)

본작의 영구 성장은 읽자마자 이해되는 기본 스탯으로 단순화한다. 체력이나 공격력처럼 한눈에 아는 수치를 수리점에서 올리고, 플레이 방식을 바꾸는 효과는 원정 중 보상이 맡는다. 수치와 해금 조건은 아래의 자체 설계다.

## 3. 세계관과 반복의 이유

### 3.1 마을의 정체

마을은 스스로 움직이고 생각할 수 있는 장난감 주민들의 실제 생활 공간이다. 중앙 대태엽이 공급하는 에너지와 주민의 의지를 제어하는 신호는 별도 회로지만, 오랜 시간 하나처럼 취급되어 왔다.

중앙 관리 인형인 대조율사 오르덴은 사고와 갈등을 없애려다 모든 선택을 표준화했다. 슬픔, 호기심, 반항을 수리해야 할 오작동으로 판정하고, 주민들이 같은 미소와 일상을 유지하게 만든다.

오르덴은 외부에서 침입한 마왕이 아니다. 마을을 지키는 역할이 통제로 변한 내부의 권력이다. 최종 목표는 그 명령 회로를 끊되 주민을 움직이는 동력은 유지하는 것이다.

### 3.2 주인공과 거점

주인공은 자율 조율 기능이 있는 구형 인형이다. 조종 신호를 받아들이는 수신축에 결함이 생겨, 명령과 자기 생각을 처음으로 구분하게 되었다. 에너지원 자체가 없어진 것은 아니므로 혼자 움직일 수 있다.

폐기장에서 발견한 태엽 렌치를 들고 나가다가 작은 수리점의 주인 모루를 만난다. 모루는 통제 장치에 순응하는 척하며 고장품들을 몰래 수리하고 있었다.

모루는 주인공의 상태를 원본 조립 기록에 적어 둔다. 쓰러진 인형은 폐기물 회수망을 통해 폐기장으로 보내지고, 모루가 같은 몸의 핵심 태엽과 기록을 회수해 다시 수리한다. 새로운 인물로 복제되거나 전날로 돌아가지 않는다. 회수망의 연결과 복구 과정은 짧은 화면 전환으로 표현하고 긴 사망 연출은 반복하지 않는다.

원정의 마지막 동력이 끊기기 전에 안전핀을 작동시키므로 코어가 완전히 파괴되지는 않는다. 이는 주인공만의 불사 능력이 아니라 모루가 설치한 비상 장치다. 안전핀을 장착할 수 있고 수거 경로가 연결된 인형에게 같은 원리를 적용할 수 있다.

### 3.3 길과 적이 다시 바뀌는 이유

마을의 외곽에서 시계탑으로 가는 길은 야간 정비망을 지나야 한다. 회전하는 블록 거리, 재배치되는 정원 통로, 생산 라인의 수송로, 시계탑의 회전 계단이 정비 주기마다 연결을 바꾼다. 각 구역의 목적지는 같지만 도달 경로와 방 구성이 달라진다.

제작한 방 하나의 구조를 전투 중에 마음대로 바꾸지 않는다. 한 원정의 경로는 진입할 때 고정하고, 이후 원정 생성 때 새 경로를 고른다. 맵 생성은 제한 없는 임의 타일 생성보다 검증된 방을 연결하는 방식으로 시작한다.

쓰러뜨리는 일반 적은 통제된 주민 자체가 아니라 반복 생산되는 경비 인형과 관리 기계다. 보스전의 몸체 역시 교체 가능한 현장 단말이며, 핵심 신호가 살아 있는 동안 재조립된다. 처음부터 보스 설명에 원격 제어핵과 교체 몸체가 보이게 하여 인간형 인물을 계속 죽였다 되살리는 인상을 피한다.

구출한 주민과 회수한 제어핵은 거점에 남는다. 보스의 현장 단말이 다시 가동되어도 이미 구출한 주민을 다시 가두지 않는다. 오르덴의 통제를 실제로 끝내는 진짜 결말 이후에는 별도의 모의 정비 도전을 사용한다.

## 4. 시작 1분과 기본 반복

### 4.1 도입

게임은 불량 판정서 모양의 타이틀에서 시작한다. 제품 번호 F2의 판정 사유는 "스스로 생각함"이고, 처리 방법 칸의 새로 시작하기, 게임 불러오기, 환경설정이 메뉴다. 새로 시작하기를 누르면 폐기 도장이 찍히고 어두워진 화면에 다음 세 문장이 차례로 나온다. 아무 키나 누르면 건너뛴다.

> 이 마을에는 불행한 주민이 없습니다.  
> 불행한 주민은 고장으로 분류되기 때문입니다.  
> 당신은 오늘 폐기되었습니다.

이어서 눈을 뜨듯 화면이 열리고 쓰러져 있던 주인공이 일어나 짧게 독백한다. 낯선 곳, 시키지 않아도 움직이는 몸, 손에 쥔 렌치를 스스로 확인한 뒤 폐기장에서 바로 조작한다. 안내는 화면 아래 한 줄씩만 나오고, 해내면 사라진다. 노란 표시까지 걷기, 슈트에서 떨어진 수거 인형을 렌치로 세 번 때리기, 머리 위 `!` 예고를 보고 회피하기, 안내 없이 쓰러뜨리기, 빛나는 수리점 문으로 걸어가기 순서다. 이미 회피를 써 본 플레이어는 회피 단계를 건너뛴다.

도입 전투는 첫 시작에 한 번만 나온다. 등록 전 패배는 재시도 화면 없이 같은 단계를 마당 시작 지점에서 바로 이어 가며, 아직 설치하지 않은 안전핀으로 복구되었다고 말하지 않는다. 도입 전투의 재료 보상은 저장당 한 번뿐이고 정식 원정 606 보상 계산에는 포함하지 않는다.

첫 적을 쓰러뜨리고 문으로 걸어가면 폐기장과 이어진 마을 좌측 상단 골목의 포탈로 나와, 계단을 내려가 광장까지 직접 걷는다. 곧 첫 종이 울려 주민이 모두 하던 동작을 멈추고, 주인공이 "왜 모두 멈췄지?"라고 독백하면 모루가 멀리서 부른다. 주민은 멈춘 채로 있고, 노란 화살표를 따라 모루에게 걸어가면 화면 아래 대화창에서 첫 대화를 나눈다. 등록 전에는 마을을 나갈 수 없다. 대사 전문은 `src/data/dialogue.json`에 있다. 이 대화가 플레이어에게 납득시켜야 할 것은 두 가지다.

- 싸워야 하는 이유: 수거되면 무음공장에서 생각이 지워지고 같은 미소로 돌아온다. 몸은 남고 나만 없어진다. 경비 인형은 신호대로 찍어 낸 기계라 말로는 멈추지 않으며, 주민은 적이 아니다.
- 마을을 나가야 하는 이유: 종이 울릴 때마다 표정을 검사받으므로 숨을 곳이 없다. 나가는 길은 웃음거리 하나이고 행진대장 브라스가 막고 있다.

대화 끝에 안전핀을 등록하면 정식 원정이 열린다. 전투방은 마지막 적이 쓰러지고 1초 뒤 보상 패널이 뜨며, 보상을 고르면 튜토리얼과 같은 노란 표시로 포탈이 열려 그곳으로 걸어 나간다. 대화는 Esc로 건너뛸 수 있고, 마을에서 모루에게 말을 걸면 다시 들을 수 있다. 강제 패배, 청소 작업, 긴 회상은 넣지 않는다. 처음부터 이기고 진행할 수 있다.

### 4.2 한 원정의 구성

> 현재 구현은 웃음거리 한 구역의 12구간입니다. 원정은 웃음 마을의 남쪽 큰길을 나서는 순간 시작되고, 전투 4 → 로코 → 중간 마을(볼트 상점) → 전투 5 → 브라스 순서로 진행합니다. 마을은 구간에 세지 않는 출발점이며, 정의는 `src/data/slice.json`의 `rooms`입니다. 아래의 4구역 29노드는 정식 범위의 목표입니다.

수리점 준비 → 웃음거리 → 리본정원 → 무음공장 → 중앙시계탑 → 대조율사 오르덴 → 귀환 및 영구 조율.

각 구역은 7개의 진행 노드를 가진다.

| 노드 | 내용                                |
| ---- | ----------------------------------- |
| 1    | 일반 전투, 보상 선택                |
| 2    | 일반 전투 또는 사건 공간, 보상 선택 |
| 3    | 해당 구역 중간 보스                 |
| 4    | 일반 전투, 보상 선택                |
| 5    | 상점·정비·NPC 중 하나인 서비스 공간 |
| 6    | 강한 일반 전투 또는 정예전          |
| 7    | 해당 구역 보스                      |

4구역의 28노드 뒤에 최종 보스 노드가 추가되어 최대 29노드다. 거점과 구역 사이의 안전 회랑은 이 숫자에 포함하지 않는다. 선택 경로는 같은 깊이에서 서로 다른 노드를 고르는 방식이며 모든 갈림길을 다 돌 수는 없다.

구역 보스 뒤에는 임시 체력 30 회복을 기본 제공한다. 이 회복은 최대 체력을 올리지 않는다. 최종 보스 직전에도 4구역 보스 뒤의 같은 회복 기회를 사용하며 추가 회복을 중복 제공하지 않는다.

장비한 렌치와 기본 능력은 유지한다. 임시 속성 부품은 공장 규격품이라 과부하 후 회수 시 손상되거나 분리되고, 다시 쓸 수 있는 부분만 연구 기록으로 남는다. 특정 실패에서만 몰래 속성을 유지하거나 소모 재화를 영구 보상처럼 표시하지 않는다.

## 5. 태엽 렌치 전투

### 5.1 기본 수치

| 항목                       | 기본값                  |
| -------------------------- | ----------------------- |
| 최대 HP                    | 100                     |
| 이동 속도                  | 3.5유닛/초              |
| 회피 거리 / 지속 / 무적    | 3유닛 / 0.18초 / 0.16초 |
| 회피 재사용 시간 / 충전 수 | 0.75초 / 1회            |
| 피격 후 무적               | 0.55초                  |
| 최대 축전                  | 100                     |
| 기본 공격 단계 적중당 축전 | 8                       |

거리 단위는 Unity 기준 유닛이며, Phaser에서는 1유닛=기준 픽셀 40으로 변환한다. 해상도 변경이 실제 이동 속도와 사거리를 바꾸지 않아야 한다.

| 단계 | 피해 | 준비 / 판정 / 회수   | 사거리   |
| ---- | ---- | -------------------- | -------- |
| 1타  | 16   | 0.12 / 0.15 / 0.15초 | 1.65유닛 |
| 2타  | 18   | 0.135 / 0.165 / 0.18초 | 1.85유닛 |
| 3타  | 28   | 0.21 / 0.21 / 0.3초  | 2.2유닛  |

1타는 빠른 횡타, 2타는 몸통을 돌리는 반대 횡타, 3타는 한 발을 디디는 내려찍기다. 몸통·팔·오른손·렌치가 한 동작으로 이어지고, 무기가 손의 축에서 독립적으로 흔들리지 않는다. 기본 공격은 적중 수가 많아도 공격 단계 하나당 축전을 한 번만 얻는다.

피격과 회피 취소 규칙은 별도 상태 머신으로 처리한다. 준비 동작에서는 회피 취소가 가능하며, 이미 활성화된 판정을 취소해 중복 공격을 만들 수는 없다. 3타 후딜의 마지막 0.1초는 회피로 줄일 수 있다.

### 5.2 축전과 융합

일반 속성 기술은 재사용 대기시간만 사용한다. 융합은 재사용 대기시간과 축전 게이지를 함께 사용한다. 축전은 기본 공격으로 얻는 것이 기본이며, 기본 상태에서 가만히 서 있으면 차오르지 않는다.

원정 전에 모루에게 속성 2개를 고른다. 두 개를 고르기 전에는 마을을 나갈 수 없다. 고른 속성은 모루의 뒷마당(폐기장)에서 쓰러지지 않는 허수아비에게 시험할 수 있다. 뒷마당의 축전은 항상 가득 차 있고, 기술 대기시간은 그대로이며 초기화 토글(T)을 켠 동안만 계속 초기화된다. 한 속성만 쓰는 조율을 선택한 플레이어는 두 번째 획득을 보류하고 다른 임시 보상을 받을 수 있다.

두 속성을 한 번 장착해 보기 전까지 1구역의 1·2번 노드는 일반 전투로 고정한다. 사건 공간이 두 번째 전투를 대체해 첫 중간 보스 전에 융합을 경험하지 못하는 경우를 막는다. 해당 경험 이후에는 정상적인 사건 공간 가중치를 사용한다. 명시적으로 단일 집중을 선택한 플레이어는 이 안내를 건너뛸 수 있다.

태엽 쥐는 무리로 달려와 붙으면 터진다. 방패 호두까기는 정면 피해를 80% 막고, 공격 뒤 회수 동안에는 방패가 내려간다.

일반 전투방은 웨이브 2~3개, 합계 10~15마리로 구성한다. 남은 적이 1마리 이하가 되면 바닥 표시 0.8초 뒤 다음 웨이브가 등장한다. 뒤 구간일수록 구성이 강해지고 적의 체력 배율도 55%에서 85%까지 오른다. 피해 배율은 체력 배율의 50%다.

### 5.3 제압과 태엽 풀기

일반 적은 큰 공격에 짧게 경직된다. 보스는 공격별 제압 누적을 받아 제압 게이지가 가득 차면 1.5초간 노출되고, 이후 8초간 다시 제압되지 않는다. 느려짐·흡입·넉백으로 보스를 영구적으로 묶지 못한다.

기본 공격 제압값의 초기안은 10/12/25, 일반 속성 기술은 시전당 최대 20, 대지 타격은 35, 융합은 최대 35다. 보스 제압 한도는 중간 보스 100, 구역 보스 150, 최종 보스 200으로 시작한다. 다단히트 수만큼 무제한 누적하지 않는다.

‘태엽 풀기’는 주요 보스 격파 후 드러난 통제축을 렌치로 푸는 짧은 마무리다. 모든 적을 처치할 때마다 추가 버튼을 누르게 하지 않는다. 처음에는 직접 조작하고 이후에는 빠른 확인과 건너뛰기를 지원한다. 보상과 사건 처리는 연출 스킵 여부와 무관하게 한 번만 발생한다.

## 6. 원정 중 빌드와 보상

모든 전투방은 완료 시 종류별 기본 자유 톱니를 자동 지급하고, 별도로 한 묶음의 3개 성장 보상 중 하나를 고르게 한다. 중간 보스와 구역 보스는 자기 종류의 기본 보상만 주며 일반 전투 보상을 중복 지급하지 않는다. 선택지로 나오는 자유 톱니는 기본 지급 외의 추가 재료다.

보상은 한 묶음의 3개 선택지 중 하나를 고른다. 보상 문구는 먼저 행동이 어떻게 바뀌는지 보여 주고, 아래에 수치를 적는다.

| 보상 종류 | 내용                                       | 유지      |
| --------- | ------------------------------------------ | --------- |
| 속성 모듈 | 아직 없는 속성 획득, 기존 한 속성 교체     | 원정 한정 |
| 기술 개조 | 장착 기술의 동작을 바꾼다                  | 원정 한정 |
| 속성 특성 | 장착 속성의 상태이상 규칙을 바꾼다         | 원정 한정 |
| 렌치 개조 | 기본 공격의 동작을 바꾼다                  | 원정 한정 |
| 기술 조율 | 장착 슬롯의 기술 단계 +1                   | 원정 한정 |
| 자유 톱니 | 풀이 바닥났을 때만 나오는 대체 보상        | 영구      |

수치 증가는 영구 스탯이 맡고, 전투 보상은 플레이 방식을 바꾸는 효과를 맡는다.

속성 모듈을 얻으면 같은 속성의 기술 두 개를 함께 연다. 같은 속성을 중복 장착할 수 없다. 세 번째 모듈을 얻으면 어느 슬롯을 교체할지 고른다. 기술 단계는 슬롯에 붙으며 같은 원정 안에서 속성을 바꿔도 단계는 유지한다.

교체는 안전한 보상 화면에서만 가능하다. 이미 사용한 기술은 해당 기술 ID의 남은 재사용 시간을 기억하며, 교체로 대기시간이나 축전이 충전되지는 않는다. 새 융합의 대기시간도 이전 융합의 남은 시간보다 짧아지지 않게 한다.

기술 단계는 1~5다. 단계당 직접 피해 +12%로, 5단계는 1단계의 1.48배다. 일반/희귀/특제 등급의 직접 피해 계수는 1/1.15/1.35다. 치료량, 보호막, 상태 지속 시간은 이 피해 계수를 자동으로 받지 않는다.

융합의 기술 단계와 등급은 장착 두 슬롯 중 낮은 값을 따른다. 한 슬롯만 강화해서 두 슬롯 전체가 최상급이 되는 편법을 막고, 어느 쪽을 강화할지 선택하게 한다.

### 6.1 보상 등장 규칙

한 번의 선택지는 3개다. 같은 카드는 중복되지 않고, 이미 얻은 개조와 특성은 풀에서 빠진다.

| 상황               | 선택지                                                       |
| ------------------ | ------------------------------------------------------------ |
| 첫 전투 2번        | 속성 모듈만                                                  |
| 4구간, 10구간      | 렌치 개조만 (무작위 3개, 원정당 2개)                         |
| 그 외 전투, 보스   | 기술 개조 또는 속성 특성 1장 보장 + 무작위 2장               |

무작위 풀은 장착한 속성의 기술 개조와 속성 특성, 미보유 속성 모듈, 기술 조율이다. 장착하지 않은 속성의 개조와 특성은 나오지 않는다. 풀이 부족할 때만 자유 톱니 +12가 대체 보상으로 나온다.

### 6.6 원정 동전과 상점

> 현재 구현에서 거점은 웃음 마을 전체이고 별도의 입구 구간은 없다. 모루와 볼트에게 다가가 말을 걸면 조율판과 상점이 열리고, 출구로 걸어 나가면 원정이 진행된다. 야시장 전 5개 구간의 전투맵은 38.4×25.6유닛이며 플레이어를 따라 화면이 움직인다. 중간 마을은 해 질 녘의 작은 야시장 맵을 쓴다. 낮의 웃음 마을에서 출발해 길을 나아갈수록 해가 지고, 야시장의 주민은 더 적지만 종이 울리면 더 오래 멈춰 선다. 주민은 말을 하지 않고 같은 발걸음으로 걷다가, 종이 울리면 그 자리에서 함께 멈춘다. 종은 주민이 모인 광장에서만 울리므로 전투 구간에서는 들리지 않는다. 첫 방문의 종은 도착 6초 뒤에 울리고, 이후의 종은 30초 간격이다.

동전은 일반 전투 완료 15, 중간 보스 25, 구역 보스 40을 기본으로 지급한다. 일반 전투 네 번씩을 고른 완주에서는 최종 보스 직전까지 500동전이며, 출발 주머니나 선택 사건은 별도다. 같은 보스에게 일반 전투의 15동전을 추가 지급하지 않는다. 상점은 가격 할인을 적용한 뒤 올림해 최소 1동전을 받는다.

| 상품              | 기본 가격 | 제공 규칙                                                    |
| ----------------- | --------- | ------------------------------------------------------------ |

## 7. 영구 성장 — 수리점의 조율판

> 7.1부터 7.5까지는 이전 A/B 조율 설계 기록입니다. 현재 구현은 아래 7.0을 따릅니다. 비용과 수치는 임시이며 밸런스 단계에서 조정합니다.

### 7.0 현재 영구 스탯

수리점에서 자유 톱니로 기본 스탯을 올린다. 각 스탯은 최대 20레벨이고, 다음 레벨 비용은 10 + 5 × 현재 레벨이다. 스탯 하나를 끝까지 올리면 1,150, 전체는 14,950 자유 톱니다. 거점에서 전체 투자금을 무료로 환급한다.

### 7.1 화면과 원칙

조율판은 기본 조율과 속성 연구 두 탭으로 구성한다. 기본 조율은 12행이며 각 행에서 A/B 하나를 활성화한다. 투자 단계는 행 단위로 공유하므로 한 행의 최대 단계 구매 비용에 두 효과의 비용을 중복 합산하지 않는다.

속성 연구는 속성마다 출력·특성·효율의 세 항목을 가진다. 각 항목은 독립적으로 구매한다. 사용 중인 속성만 해당 연구 효과를 받는다.

거점에서 전체 투자금 100% 무료 환급과 재분배를 제공한다. 원정 도중에는 바꿀 수 없다. 성장 재료를 잘못 썼다는 이유로 새 속성을 시도하지 못하는 상황을 피한다.

### 9.1 웃음거리 융합 형태 확정

눈보라 송풍과 이온 송풍은 전방 지속 부채꼴이 겹치므로 각각 **빙풍 절단**과 **폭뢰 부유구**로 교체한다. 초전도 고리는 **자성 빙쇄**로 교체한다. 세 교체안은 두 속성 조합과 기존 총 직접 피해·재사용·축전 예산을 유지한다.

- 빙풍 절단: 빈 왼손에서 두 초승달 칼날을 한 번에 X자로 방출한다. 한 번의 손 뻗기로 두 칼날이 같은 발사점·시각·진행 속도를 공유하며, 바닥에서 좌우로 번갈아 긋지 않고 공중에 세워진 세로 X자 한 쌍이 전방으로 함께 날아간다. X의 절반 폭 0.85/절반 높이 1.35로, 가로로 눕거나 넓게 퍼지지 않는다. 발사 순간의 왼손에서 작게 형성되고 지면 위로 들어 올려져 진행한다. 화면 방향에 따라 X가 선으로 납작해지지 않도록 시각 효과의 교차면은 카메라를 향한다. 0.18초 예고 뒤 50 피해 두 판정을 같은 순간에 적용하며 총 피해 100, 재사용 22초, 축전 65는 유지한다. 지면 판정은 기존 두 꺾은선(손앞 전방 0.32/왼쪽 0.2 → 전방 1.2/측면 ±1.6 → 전방 5/측면 ∓1.6, 반폭 0.45)을 같은 시각에 평가하며 칼날당 중복 피해는 없다. 잔류 피해나 새로운 무적은 없다.
- 자성 빙쇄: 초전도 고리를 교체한다. 빈 왼손으로 사거리 6 내 지점을 지정하며 시전 후 중심과 방향은 고정된다. 해당 지점 양쪽에 얼음 턱이 솟아나고, 첫 타격 0.12초 전부터 안쪽으로 닫힌다. 0.6초 예고 후 압착, 0.78초 중앙 방전, 0.96초 파쇄의 3타(각 32, 합계 96)를 적용한다. 실제 판정은 조준 방향 전후 길이 3.6×좌우 폭 2.5의 사각 범위이며 표기 반경 2.2는 외접 범위 참고값이다. 양측 턱의 거리(중심에서 2.1→0.7)는 시각 위치이며 별도 물리 벽을 생성하지 않는다. 기존 둔화·감전만 적용하고 새 속박·끌어오기·보스 강제 이동·잔류 장판 피해는 추가하지 않는다. 재사용 20초, 축전 65와 시전당 상태·경직 제한을 유지한다.
- 화염 회오리: 캐릭터 전방 2.6에서 생성되어 초당 2.2 속도로 전진한다. 벽 앞에서는 기존 이동 충돌 규칙에 따라 멈춘다. 생성 오프셋은 시각 효과와 실제 피해·흡입 중심에 동일하게 적용한다. 기존 8타, 피해·재사용·축전 예산과 타격 시점은 유지한다.
- 폭뢰 부유구: 빈 왼손으로 사거리 6 안의 지점을 지정한다. 바닥에 예고 범위를 표시하고 지점 위에 구체를 띄운다. 설치 위치는 시전 후 고정되며 0.85초 뒤 반경 3에서 한 번 폭발한다. 명중한 일반 적만 중심 반대 방향으로 0.65 이동시키고, 보스는 피해·상태만 받으며 이동하지 않는다. 폭발 후 추가 피해 장판은 남기지 않는다.
- 오른손에는 긴 렌치 한 개를 유지한다. 준비·발동·복귀·효과 소멸을 분리하고, 8방향 및 몸체/바닥/입자 레이어를 독립 데이터로 관리한다. 애니메이션 검토용 준비 160ms는 이 표의 실제 예고에 더하는 게임플레이 지연이 아니다.

융합은 시전 시작 시 축전과 대기시간을 함께 지불한다. 대기시간은 게임 내 시전 시작 시점부터 흐른다. 두 속성 상태를 적용하는 기술도 같은 시전 ID 아래에서 상태 적용 간격을 지켜야 한다.

수정 보루의 보호막은 20, 황혼 평형은 12이며 보호막 규칙을 따른다. 반사 수류의 회복은 8이며 빛 회복 예산을 공유한다. 빛·대지 보호막 연구가 함께 장착되면 수정 보루에는 두 연구 중 큰 보정만 적용한다.

## 10. 계산·상한·악용 방지

### 10.1 피해 계산

직접 타격 피해 = 기본 직접 피해 × (1 + 영구 보정) × (1 + 원정 피해 보정) × 기술 단계 계수 × 등급 계수 × 치명타 계수 × 대상 취약 계수.

- 영구 보정은 적용 가능한 공통·기본 공격·속성 출력·후면·상태 연결 등을 더하되, 한 타격의 합계는 +60%를 상한으로 한다. 대기시간과 치명타 확률 같은 다른 종류의 능력치를 이 합계에 넣지 않는다.
- 원정 피해 보정은 같은 종류를 합산하고 +80%를 기본 상한으로 한다. 추가 타격이나 궤적 변화는 별도 효과이며 독립 피해 원본을 가진다.
- 기본 공격은 기술 단계·등급 계수를 1로 둔다. 속성 기술과 융합에만 해당 단계·등급을 적용한다.
- 균열의 기본 공격 취약 +8%는 대상 취약 계수다. 여러 취약 효과가 생기면 합산하고 +30% 상한을 둔다.
- 화상·침식의 주기 피해는 해당 속성의 공통·출력 보정과 원정 상태 피해 보정만 받는다. 기술의 타수·치명타·기술 등급으로 중복 증폭하지 않는다.
- 치명타 기본 확률은 0%, 기본 피해 배율은 1.5배, 모든 효과를 합친 확률 상한은 20%다. 보호막·치유·주기 피해는 기본적으로 치명타가 없다.

### 10.2 대기시간과 보호막

재사용 시간 = 기본 시간 × (1 - 총 감소율). 기본 조율, 속성 연구, 임시 강화의 감소율을 합산하되 최대 35%다. 회피는 별도 계산을 사용하고, 윤활 회피축을 적용한 뒤 임시 회피 감소를 적용하되 최저 0.45초를 유지한다. 회피 무적 시간은 성장으로 늘리지 않는다.

보호막은 원천이 달라도 더하지 않는다. 새 보호막량이 현재 남은 양 이상일 때만 새 양과 새 지속 시간으로 교체하고, 작으면 현재 보호막과 만료 시각을 그대로 둔다. 결과값은 최대 HP의 50% 이하로 제한한다. 작은 보호막을 계속 걸어 더 큰 보호막의 지속 시간을 늘릴 수 없다.

흡입·넉백은 일반 적에게만 완전 적용한다. 보스에게는 강제 이동 대신 명시한 제압 효과만 적용한다. 바람 돌진과 그림자 천공은 기본적으로 무적이 아니며, 이를 회피 버튼 대체로 오해하지 않도록 아이콘과 설명을 구분한다.

모든 돌진과 강제 이동은 벽·낭떠러지·잠긴 문 판정을 존중한다. 회피나 융합을 이용해 닫힌 진행 노드를 건너뛰거나 이동 불가능한 곳에 갇히지 않게 한다.

### 10.3 보상과 저장

전투방 보상은 최초 완료 때만 지급한다. 소환 적을 무한히 남기거나 상자와 방을 재입장해 자유 톱니를 반복 지급받지 못한다. 보스가 호출한 소환 적은 추가 영구 재료를 주지 않는다.

영구 재료와 해금은 방 보상 확정 시 원정 ID·방 ID와 함께 저장한다. 재접속 시 재지급하지 않는다. 설정 변경, 일시정지, 대화 중에는 전투와 축전 재생 시간이 흐르지 않는다.

원정 중 종료 시 현재 방 진입 상태를 저장하며, 계속하기는 같은 난수 시드와 보상 상태를 복구한다. ‘원정 포기’는 이미 확보한 영구 재료를 유지하고 임시 성장만 잃는다. 포기로 새로운 무료 보상을 만들지는 않는다.

### 12.1 웃음거리 중간 보스 — 회수관 로코

바퀴 달린 수거 상자와 커다란 집게팔을 가진 인형이다. 처음에는 쓰레기통처럼 보이다가 ‘고장품’ 표시를 보고 주인공을 집어 넣으려 한다.

패턴은 직선 집게 뻗기, 바닥 자석 구역 생성, 과충전 후 짧은 정지다. 자석은 이동을 완전히 빼앗지 않으며 표시된 반대 방향으로 빠져나갈 수 있다. 집게를 피하면 팔 관절이 열려 반격할 수 있다.

- 등장: “고장품 확인. 올바른 장소로 옮깁니다.”
- 격파 후 주인공: “올바른 장소는 내가 고를게.”

첫 로코 격파 또는 누적 전투방 8개 완료 시 대지·물·빛·어둠을 보상 풀에 연다. 초기 네 속성만 강제로 오래 쓰게 하지 않는다.

### 12.2 웃음거리 보스 — 행진대장 브라스

금관 악기처럼 빛나는 갑옷을 입은 장난감 대장이다. 마을의 즐거운 행진을 지휘하지만 주민들이 걸음을 멈추면 강제로 같은 박자로 돌려놓는다.

패턴은 부채꼴 2연타, 세 줄 행진 돌진, 나팔 파동이다. HP 50%에서 행진 경로가 하나 추가되지만 안전한 틈은 항상 남긴다. 보스가 음악을 멈추고 숨을 고르는 순간은 공격 기회다. 리듬 게임 수준의 박자 입력은 요구하지 않는다.

- 등장: “박자가 다르면 모두가 넘어집니다. 줄을 맞추십시오.”
- 첫 격파 기록: ‘마을의 행진은 주민의 선택이 아니라 명령이었다.’

통제축을 풀어 경비 순찰 설계도를 얻는다. 외곽 첫 문을 열지만, 시계탑의 본신호가 남아 있어 다음 정비 주기에는 새 몸체가 배치된다.

### 12.3 리본정원 중간 보스 — 재봉사 핀

거대한 바늘과 색색의 실패를 든 재봉 인형이다. 예쁘게 단장해 준다며 주인공의 관절을 꿰매려 한다.

패턴은 바늘 직선탄, 리본을 연결하는 두 지점, 짧은 추적 재봉선이다. 연결선에 닿으면 1초간 느려지며, 계속 닿아도 기본 둔화 이상으로 조작을 마비시키지 않는다. 바늘을 던진 뒤 실을 감는 동안 노출된다.

- 등장: “삐뚤어진 곳은 꿰매면 돼요. 움직이지 마세요.”
- 사건 보상: 끈을 끊고 스스로 춤추려던 주민 ‘리본’의 첫 흔적.

### 12.4 리본정원 보스 — 회전목마 여왕 멜로디

회전목마의 중심축과 결합한 아름다운 도자기 인형이다. 주민이 다치지 않도록 한 자리에서 영원히 춤추게 하는 것이 자신의 돌봄이라고 믿는다.

패턴은 원형 회전 말 돌진, 안전 구간이 움직이는 고리 탄막, 잠깐 멈춘 뒤 이어지는 역회전이다. 바닥의 장식 패턴이 다음 돌진 길을 먼저 알려 준다. HP 50%에서 회전 방향이 바뀌되 화면 전체를 가리는 효과는 없다.

- 등장: “밖은 위험해요. 여기서는 아무도 넘어지지 않아요.”
- 주인공: “넘어질 수 있어야 멈출 수도 있지.”

첫 제어핵 회수 후 리본이 수리점으로 합류한다. 이후 재등장하는 멜로디 현장 몸체는 중앙 자동 신호로 작동하는 대역이며, 회수한 제어핵을 다시 가두지 않는다. 리본은 기동 조율과 NPC 사건을 담당한다.

### 12.5 무음공장 중간 보스 — 검수관 아이리스

렌즈 눈과 ‘합격/불량’ 도장을 가진 검사기다. 주인공의 부품을 훑으며 규격 밖의 생각을 검사한다.

패턴은 예고되는 부채꼴 탐조등, 그 뒤의 레이저, 바닥 불량 도장 세 곳이다. 탐조등에 닿았다는 이유로 즉사하거나 무조건 맞지는 않는다. 레이저 발사까지 피할 여유를 준다. 렌즈를 조정하는 뒤편이 빈틈이다.

- 등장: “자발적 행동 검출. 재검사 대상입니다.”
- 첫 기록: 주민의 웃음이 ‘행복 확인’보다 ‘동일성 검사’에 쓰였다는 사실.

### 12.6 무음공장 보스 — 총감독 프레스

거대한 프레스와 여러 개의 정형 틀을 조종하는 관리 기계다. 서로 다른 장난감을 같은 몸체로 눌러 만들려 한다.

패턴은 바닥 그림자 뒤 내려오는 압착판, 컨베이어 이동, 규격 경비 소환이다. 소환 경비는 최대 3기다. 프레스 두 팔 중 한쪽 공격을 유도하면 그 팔의 공급축이 잠깐 노출되어 제압값을 크게 줄 수 있다.

- 등장: “차이가 줄어들면 고장도 줄어듭니다.”
- 첫 격파 보상: 주인공의 구형 자율 조율 설계도. 스스로 움직이는 기능은 원래부터 가능한 기능이었음이 드러난다.

이 사건은 운명적으로 선택받은 주인공이라는 결론이 아니다. 모루는 다른 주민에게도 자율 조율 기능을 복원할 길을 찾기 시작한다.

### 12.7 중앙시계탑 중간 보스 — 시간지기 틱·톡

서로 다른 색의 작은 시계 인형 둘이 하나의 제어핵을 공유한다. HP 1,300은 두 기의 합계이며 적별 체력을 더해 2,600으로 만들지 않는다.

한 기는 근접 찌르기, 다른 기는 느린 부채꼴 탄막을 맡는다. 짧은 예고 후 역할을 교환한다. 양쪽이 동시에 피할 수 없는 방향으로 공격하지 않도록 공격 예약기를 공유한다. 이름과 달리 실제 입력을 멈추거나 시간을 되감는 능력은 없다.

- 등장: “한 걸음 빠르면 불안정. 한 걸음 느리면 불량.”
- 주인공: “난 내 속도로 갈 거야.”

### 12.8 중앙시계탑 보스 — 종루수호자 벨가드

몸통에 거대한 종을 달고 있는 중장갑 문지기다. 종소리를 통해 마을의 명령을 중계한다.

패턴은 바닥 고리 충격파, 종추 휘두르기, 신호 증폭 상태다. 증폭 중에는 수호자만 때리는 대신 주변 중계기 두 개를 끊어 방어 상태를 빠르게 끝낼 수 있다. 방어는 피해 감소 40%이며 무한 무적이 아니다. 중계기를 못 끊어도 6초 뒤 정상 상태로 돌아온다.

- 등장: “이 종이 멈추면 마을이 흔들립니다.”
- 첫 통제축 해제: 동력선과 명령선이 별개라는 물리적 증거를 얻는다.

이 보스가 최종 보스와 다른 이유는 방송의 중계기와 명령의 작성자가 다르기 때문이다. 벨가드 뒤의 정비 회랑에서 잠깐 회복하고, 오르덴에게 도전한다.

### 12.9 최종 보스 — 대조율사 오르덴

겉모습은 친절한 시계공 인형이다. 상체는 작고 단정하지만 전투가 진행되면 등 뒤에서 마을 전체와 이어진 거대한 조율 장치가 펼쳐진다. 마을의 통제자는 단순히 주민을 괴롭히려는 침입자가 아니라, 실패와 갈등을 없애려던 관리 인형이다.

- 첫 대면: “너는 고장 난 것이 아니다. 네 선택이 마을을 고장 내고 있다.”
- 주인공: “그럼 마을도 고칠 수 있겠네. 날 버리는 것 말고 다른 방법으로.”

1단계 HP 100~65%는 정밀한 렌치 찌르기와 지정 위치의 톱니탄이다. 2단계 65~30%에는 네 구역 보스의 명령 동작을 하나씩 호출한다. 두 패턴을 겹칠 때는 동일 방향의 회피가 가능한 조합만 허용한다. 3단계 30~0%는 조율 장치가 벌어지고 큰 공격 뒤 명확한 반격 창이 생긴다.

전체 HP 6,400을 세 단계가 공유한다. 단계마다 HP를 6,400으로 다시 채우지 않는다. 단계 전환의 무적은 각각 최대 1.5초이며 긴 대사를 강제로 읽히지 않는다.

특정 속성 저항이나 보호막을 필수 열쇠로 삼지 않는다. 어떤 두 속성 조합이나 기본 공격 중심 빌드도 이길 수 있어야 한다. 보스의 위협은 원정 성장을 무효화하는 상한 없는 체력보다 패턴 해석과 위치 선택에서 만든다.

## 13. 반복 플레이에 녹는 시나리오

### 13.1 첫 목표 — 탈출

주인공은 처음에는 마을 밖으로 나가려 한다. 수리점의 작은 창 너머로 주민들이 같은 시간에 인사하는 모습을 보고 이상함을 느끼지만, 처음부터 해방 운동의 지도자가 되지는 않는다.

모루는 멈추는 법과 다시 움직이는 법을 가르치고, 주인공은 원정을 통해 실제 통제축을 본다. 사건은 장문의 일기보다 짧은 보스 대사, 상호작용 물건, 수리점 인물 변화로 전달한다.

### 13.2 귀환 뒤 사건

대화는 한 번에 핵심 사건 하나만 우선 재생하고, 나머지는 아이콘으로 남겨 원할 때 읽는다. 다시 출발하기 위해 모든 대화를 소진할 필요는 없다.

| 계기                  | 사건                                                | 영구 변화                              |
| --------------------- | --------------------------------------------------- | -------------------------------------- |
| 첫 실제 패배          | 모루가 같은 몸의 코어를 고쳐 다시 움직이게 함       | 조율판 소개, 1회 초보 보너스 조건 확인 |
| 첫 중간 보스 발견     | 회수 인형도 중앙의 폐기 규격을 따른다는 단서        | 2티어 조율 접근 조건 충족              |
| 브라스 첫 통제축 해제 | 웃음거리의 일상이 명령으로 유지됨을 확인            | 순찰 설계도와 인장 기록                |
| 멜로디 첫 제어핵 회수 | 리본이 자신의 걸음으로 수리점에 도착                | 기동 조율 사건, 새 임시 개조 설계도    |
| 프레스 첫 설계도 회수 | 자율 조율은 원래 가능한 기능이었음                  | 모루의 주민 복원 연구                  |
| 벨가드 첫 통제축 해제 | 동력과 행동 명령을 분리할 수 있음                   | 마지막 사건 해결의 근거                |
| 오르덴 첫 격파        | 외곽 출입문이 열리고 주인공은 실제로 마을 밖에 나감 | 첫 엔딩, 자유 조율 연구 접근           |

패배 횟수 자체로 핵심 대사를 잠그지 않는다. 첫 원정을 완주한 플레이어도 보스의 첫 회수 기록과 귀환 사건을 통해 정보를 받을 수 있다. 적게 죽었다고 설정을 놓치면 안 된다.

### 13.3 첫 엔딩과 돌아오는 이유

첫 오르덴 격파는 명령 작성 단말을 정지시켜 바깥문을 여는 데 성공한다. 주인공은 문을 넘는다. 이는 가짜 탈출이나 강제로 되돌아가는 반전이 아니다.

그러나 뒤를 돌아보면 주민들은 여전히 중앙의 예약 명령을 반복하고 있다. 주인공은 살아 나갈 수 있지만, 자신과 같이 버려질 주민들이 남아 있음을 안다. 수리점으로 돌아가는 행동은 다음 이야기의 자발적인 선택이다.

- 주인공: “문은 열렸어요.”
- 모루: “그래. 이제 네가 갈 곳을 고르면 돼.”
- 주인공: “…이번엔 혼자 나가는 것 말고요.”

첫 격파 후에도 분산된 예약 명령망이 단말을 복구하므로, 단말을 이기는 것만으로 전체 통제가 사라지지 않는다. 이 규칙은 첫 엔딩 기록에 명시한다. 최종 보스가 실제로 죽은 생명체인데 설명 없이 부활한 것으로 처리하지 않는다.

### 13.4 진짜 결말 — 동력은 남기고 명령을 끊는다

첫 탈출 뒤 세 가지 연구 사건을 완료한다.

1. **자율 설계 검증:** 프레스 구역의 설계도를 모루에게 전달하고, 수리점 시험 장치에서 안전하게 조율한다.
2. **동력·명령 분리:** 벨가드의 통제축 기록을 바탕으로 분리 부품을 완성한다. 인장을 별도로 추가 소비하지 않는다.
3. **주민의 선택:** 리본 등 구조한 주민의 동의를 받아 자율 조율을 시험한다. 귀환 후 짧은 사건으로 진행한다.

해당 기록은 이미 최초 보스 격파 때 얻었을 수 있으며, 동일 보스를 연구 재료 명목으로 여러 번 잡도록 요구하지 않는다. 연구에는 추가 승리 횟수나 큰 재화 세금을 부과하지 않는다. 첫 엔딩 뒤 연구를 마치면 다음 완주에서 진짜 결말에 도전할 수 있다.

마지막 승리 뒤 모루의 분리 부품을 연결하면 마을의 동력은 흐르지만 ‘웃어라·멈춰라·버려라’라는 신호만 끊긴다. 주민들은 조금씩 다른 방향을 보고, 누군가는 처음으로 미소를 멈춘다. 행복하지 않은 표정도 고장이 아니라는 결말이다.

- 오르덴: “실수할 것이다. 다툴 것이다. 다시 부서질 것이다.”
- 주인공: “그럼 고치면 돼. 버리지 말고.”

진짜 결말 뒤에는 마을이 실제로 변한다. 같은 보스를 끝없이 생존해 있는 오르덴으로 소환하지 않는다. 이후 원정은 저장한 경비 설계로 돌리는 ‘모의 정비망’에서 고난도·기록·다른 빌드를 즐기는 별도 모드로 제공한다. 과거 사건을 다시 보는 회상 원정은 본편 상태와 분리한다.

## 14. 거점 인물과 시설

| 인물/시설            | 역할                                 | 성장과 이야기                                   |
| -------------------- | ------------------------------------ | ----------------------------------------------- |
| 모루 / 작업대        | 기본 조율, 재분배, 비상 수리         | 과거 중앙 장치 수리에 참여한 사실을 서서히 고백 |
| 리본 / 움직임 시험대 | 기동 조율 설명, 연습 표적, 훈련      | 정해진 춤 대신 자기 동작을 만들어 감            |
| 볼트 / 작은 상점     | 원정 상점의 교환 규칙, 외형 교환     | 통제를 피하려는 중립적 장사꾼에서 협력자로 변화 |
| 원소 연구대          | 8속성 연구와 융합 도감               | 보유한 효과와 발견한 효과를 구분                |
| 출발문 / 정비 지도   | 다음 원정 시작, 난도 선택, 이전 기록 | 복귀마다 긴 접수 대화 없이 바로 출발            |

거점 시설을 세우려고 기본 공격·회피·기본 조율을 잠그지 않는다. 초기 연구대는 간단한 작업판으로 시작하고, 이후 외형과 선택지가 확장된다. 실제 기능 해금에 필요한 인물 사건은 승리 외의 누적 탐험 경로로도 진행할 수 있게 한다.

## 15. 난도와 반복 가치

첫 클리어 뒤 ‘과조율’을 선택한다. 조건을 합쳐 원정 난도 등급을 올리되 수치만 무한히 올리는 방식은 제한한다.

| 조건        | 초기 단계안 | 변화                                                   |
| ----------- | ----------- | ------------------------------------------------------ |
| 강화 경비   | 1~3         | 일부 정예 배치 증가, 최대 3기 동시 공격 예약 원칙 유지 |
| 과부하 회로 | 1~3         | 적 피해 단계당 +10%                                    |
| 내구 규격   | 1~2         | 적 HP 단계당 +10%                                      |
| 불안정 설비 | 1~2         | 별도 예고가 있는 환경 장치 추가                        |
| 엄격한 검수 | 1~2         | 상점 가격 +10%씩, 기본 생존 수단은 제거하지 않음       |
| 확장 명령   | 1           | 구역 보스별 새 패턴 하나, 단순 속도 증가와 분리        |

보스 속도 상한을 넘어 예고를 읽을 수 없게 만들지 않는다. 원정 난도는 영구 능력치에 자동 연동하지 않는다. 더 높은 과조율의 최초 인장과 외형·도감 보상으로 반복 목표를 제공한다.

원정 시드, 사용한 속성 조합, 선택한 조율, 도달 구역, 받은 피해와 완주 시간을 기록한다. 일일 도전은 향후 선택 기능이며, 기본 성장 재료를 일일 접속 보상으로 잠그지 않는다.

## 16. 픽셀 아트와 UI

장난감 캐릭터의 기본 키는 약 40~56원본 픽셀 범위를 아트 테스트에서 비교한다. 필터는 nearest, 기본 확대는 정수 배율을 사용한다. 아트 크기를 정하기 전 기존 캐릭터 시트를 무조건 축소하지 않는다.

웃음거리는 크림·민트·분홍·빨강을 중심으로 하고, 통제 장치는 남색 금속과 가는 자주빛 신호선으로 드러낸다. 단순히 지하로 내려갈수록 화면 전체를 어둡게 만드는 대신, 더 깨끗하고 반듯한 공간에서도 섬뜩함을 만들 수 있게 한다.

주인공은 비대칭 수리 자국, 다른 색의 단추, 짧은 스카프와 렌치 실루엣으로 구분한다. 부품 장착은 렌치의 작은 코일·전구·밸브와 타격 효과로 표시하며 몸 전체를 번쩍이게 하지 않는다.

HUD는 왼쪽 위 HP, 상단 현재 구역과 진행 노드, 아래 기본 기술 4칸과 융합 1칸·축전 게이지로 구성한다. 영구 톱니와 임시 동전은 아이콘 외곽과 라벨을 다르게 한다.

조율판은 이름·현재 단계·다음 효과·가격을 한 줄에서 읽을 수 있어야 한다. 최대 단계까지 눌러야 실제 효과를 알 수 있는 UI는 피한다. A/B 전환 전후의 HP, 피해, 대기시간은 비교 표시한다.

큰 범위 공격은 바닥 예고 → 판정 → 잔여 효과 순서로 표현한다. 보호막, 빙결, 적 공격 표시가 같은 색일 때는 테두리 형태와 패턴을 달리한다. 화면 흔들림·섬광·피해 숫자는 설정에서 줄일 수 있다.

## 17. 데이터와 Unity 이식 준비

현재 함께 둔 JSON은 **기획용 데이터**이며 게임이 읽는 `src/data`와 분리되어 있다. 기존 플레이어, 전투 수치, 저장 파일이나 실행 중인 데모를 바꾸지 않는다.

기획용 데이터는 단위, 플레이어 기본값, 성장 행과 비용 배열, 속성, 스킬, 28개 무순서 조합, 지역과 보스 수치를 포함한다. 구현 단계에서는 다음처럼 역할별 파일로 나눌 수 있다.

| 데이터                           | 담당                                         |
| -------------------------------- | -------------------------------------------- |
| player-base.json                 | 기본 HP·이동·렌치 3타·회피                   |
| permanent-upgrades.json          | A/B 조율, 단계, 가격, 상한                   |
| elemental-research.json          | 속성별 출력·특성·효율                        |
| elements.json / skills.json      | 속성 8종과 기본 기술 16개                    |
| fusions.json                     | 두 속성 키, 융합 28개, 상태와 타수           |
| encounters.json / bosses.json    | 일반 적·보스 수치와 패턴 참조                |
| rooms.json / run-generation.json | 검증된 방, 연결 규칙, 보상 가중치            |
| hub-events.json / story.json     | 사건 조건, 대사 ID, 한 번만 발생하는 변화    |
| save-schema.json                 | 투자 단계, 해금, 도감, 사건과 보상 수령 기록 |

수치와 기술 정의는 엔진 독립 값으로 두고 Phaser 객체, Unity GameObject, 함수 문자열을 저장하지 않는다. 실제 판정은 코드의 작은 효과 실행기들이 담당한다. 기획 JSON의 한국어 효과 설명은 사람용 요약이며 실행 코드가 아니다. 구현 시 모든 효과를 명시적 타입과 매개변수로 옮겨야 한다.

저장에는 원소 이름이 아니라 고정 ID를 사용한다. 성장 버전이 바뀌면 구매 기록에 맞춰 환급·이관하고, 기존 Scriptfall 세이브를 새 세계관의 동일 저장으로 오해하지 않도록 별도 제품/콘텐츠 키를 사용한다. 임시 원정과 영구 성장 저장은 구분한다.

## 18. 제작 순서와 검증

### 18.1 우선 제작할 수직 조각

웃음 마을 거점 + 웃음거리 12구간 + 렌치 3타 + 회피 + 불/얼음/전기/바람 4종 + 이 중 가능한 융합 6개 + 로코/브라스 + 기본 스탯 13종을 먼저 완성한다. 이것은 첫 제작 범위이며 정식 기획의 8속성·28융합을 축소 확정하는 뜻이 아니다.

그다음 남은 속성과 전체 성장, 리본정원과 무음공장, 시계탑과 최종 보스, 인물 사건과 엔딩, 과조율 순으로 확장한다. 캐릭터·배경 전종을 먼저 그린 뒤 전투를 확인하는 방식은 피한다.

### 18.2 필요한 검증

- 8속성 각각 정확히 2개의 기본 기술과 연결되는가.
- 28조합이 빠짐없이 있고 역순으로 중복되지 않는가.
- 두 속성일 때 기술 4개와 융합 1개만 활성화되는가.
- A/B 공유 단계의 비용을 이중 지불하거나 두 효과를 동시에 받지 않는가.
- 무료 재분배를 반복해 재료가 늘거나 구매 기록이 유실되지 않는가.
- 융합 피해에 두 속성의 영구 출력이 중복 적용되지 않는가.
- 빛과 침식 회복 예산을 재입장·일시정지·소환 적으로 초기화하지 못하는가.
- 회피·보호막·제압 상한이 실제 전투 판정과 일치하는가.
- 첫 패배, 첫 승리, 첫 원정 완주 모두에서 도입이 자연스럽게 이어지는가.
- 구출한 주민과 첫 인장 보상이 재출현 보스 때문에 취소·중복되지 않는가.
- 무강화 숙련 플레이와 초반 권장 강화 플레이에서 첫 구역을 모두 돌파할 수 있는가.
- 초반 실패와 완주가 각각 합리적인 재료 획득 속도를 가지는가.
- 첫 클리어 전에 모든 성장을 요구하거나, 성장 완료 뒤 적이 자동으로 강해지지 않는가.
- 진엔딩 조건이 사망 횟수나 큰 반복 재화 세금으로 잠겨 있지 않은가.

이번 문서와 JSON의 개수·가격 합계는 정적으로 확인할 수 있지만, 플레이 시간·첫 클리어 투자량·보스 체력·기술 간 위력은 실제 게임 테스트가 필요하다. 아직 그 검증이 끝났다고 표현하지 않는다.
