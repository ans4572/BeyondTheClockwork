# 부품 행상 볼트 N2B·행진 주민 24종

**게임의 주민, 모루, 볼트는 모두 [PixelLab 스프라이트](pixellab/residents-preview.png)를 씁니다.** 주민은 고유 디자인 12종과 색 변형 12종, 모루는 N1A, 볼트는 N2B이며 합계 408클립입니다. 목록은 `pixellab/residents.json`, 생성은 `scripts/build-resident-sprites.mjs`입니다. 아래 로컬 리그 클립은 게임에 쓰이지 않습니다.

[재생 화면](index.html) · [전체 안내](/art/animations/README.md)

제작 방식: local_rig. 현재 등록된 본체 클립 400개입니다. R1~R20은 `characters.json`에서 C1~C4의 색과 머리, 모자, 소품을 바꾼 변형입니다. R13~R20은 새 모자(중절모, 밀짚모자, 고깔모자, 베레모)와 새 소품(풍선, 막대사탕, 꽃다발, 북)을 씁니다. 소품 색은 `colors.prop`으로 바꿀 수 있고, 재생 화면은 원본 C1~C4만 보여 줍니다.
