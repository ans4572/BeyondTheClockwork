# F2 v2 · 160클립 다시 그리기 (2026-11-26)

3챕터 보스보다 F2가 단순해 보이는 문제와 원래부터 있던 '왼손이 안 보이는' 문제를 함께 고친 F2 전체 스프라이트다. 디자인과 크기는 그대로 두고 명암·금속 표현을 보스 수준으로 올렸다. 헬멧의 초록 천 조각을 없앴고, 빈 왼손을 검은 기계 장갑으로 그렸다. 게임은 이 폴더의 시트를 쓴다(`../game-clips.json`).

## 기준 그림 `bases/`

8방향 96×96. 정면은 시범 제작 v2(`../restyle-pilot-v1/base-south-v2-clean.png`)의 왼팔 끝에 `inpaint_image_pro_flash`로 장갑 손을 그린 것이다. 나머지 7방향은 각 방향의 기존 그림을 `edit_image_pro_flash`(method=reference)로 다시 그렸다. 기존 그림은 PixelLab 캐릭터 3f7a0f77의 회전 그림이고, 서쪽은 긴 렌치 v2, 북서쪽은 렌치 고정 v3다. 기준은 새 정면 그림이다. 동쪽은 헬멧 얼룩이 검은 덩어리로 남아 인페인트로 한 번 더 지웠다.

## 클립 `clips/<동작>-<방향>/`

모든 클립은 PixMiniMax로 만들었다. 기준 그림을 캔버스 가운데에 두고, 같은 그림을 마지막 프레임으로 고정했다.

| 동작 | 캔버스 | 생성 프레임 | 길이 |
|---|---|---|---|
| 대기·걷기·달리기 | 132 | 8·12·12 | 1600·720·480ms 반복 |
| 1타·2타·3타 | 192 | 16·12·16 | 800·850·1100ms |
| 기술 8종(과열 휘두르기 … 와류 흡입) | 192 | 12 | 기존과 같음(400~800ms) |
| 피격·사망·회피 | 132 | 8·12·8 | 360·1300·180ms |
| 시전 몸동작 3종(앞으로·지점·자신) | 144 | 12 | 720ms |

- 시전 3종은 이제 남동쪽도 따로 있다. 전에는 정면 그림을 빌려 썼다.
- 사망은 마지막 프레임을 고정하지 않았다(쓰러진 채로 끝남).
- `frames/000.png`는 입력 자세라 재생에서 빼고, 발 위치와 키를 잴 때만 쓴다.

## 다시 만든 것과 손본 프레임

- 도전 스패너의 앞·옆 5방향: 전기 효과가 몸 전체를 번쩍이게 해서 효과 없는 찌르기로 다시 만들었다(번개는 게임이 그림).
- 북서쪽 달리기·1타·3타: 렌치가 몸 뒤로 사라져서 다시 만들었다. 달리기는 아직 몇 프레임에서 렌치 머리가 가려진다.
- 북쪽 돌진: 몸이 화면 안쪽으로 작아져서 다시 만들었다.
- 프레임 교체(`frame-fixes.txt`): 피격 흰 번쩍임 2장, 회피 잔상 덩어리 2장, 자신 시전에 박힌 폭발 고리 3장을 옆 프레임으로 바꿨다.
- `jobs.tsv`: 클립마다 PixelLab 작업 번호(나중 줄이 채택본).

## 왼손 다듬기 (같은 날 2차)

- 정면·남서: 어깨 패드 바로 밑에 붙어 짧아 보이던 왼팔에 소매·아래팔 마디를 넣고, 손을 엉덩이 높이의 둥근 주먹으로 바꿨다(`inpaint_image_pro_flash`, 정면은 손만 한 번 더).
- 서쪽: 무릎까지 내려오던 막대 같은 왼팔을 굽혀 손이 몸통 옆에 붙게 했다. 다리는 깨끗하게 다시 그렸다.
- 이 세 방향의 60클립을 새 기준 그림으로 모두 다시 만들었다. 프롬프트에는 '왼팔은 짧은 원래 길이, 작은 주먹'을 넣었다.
- 함께 고친 것: 북서 달리기(손 흔들기), 냉각장 6방향(팔이 바닥까지 늘어남 → 무릎을 굽혀 몸을 낮춤), 뒤쪽 3방향의 앞으로 시전(팔을 옆으로 듦).
- 비교: `left-hand-before-after.png`. 생성 103회.
- 같은 날 3차: 남서쪽만 헬멧이 흰 상아색이라 남서 20클립(과 기준 그림)의 헬멧 4색을 정면 색으로 바꿈(242,237,206 → 235,216,168, 222,207,165 → 223,200,149, 200,178,135 → 206,176,127, 176,148,106 → 184,148,104). 생성 0회.
- 같은 날 4차: 방향마다 헬멧 색이 조금씩 달라(서·북서 초록빛, 북동 복숭아빛, 동 분홍빛, 남동 흐린 흰색) 좌우로 돌 때 바뀌어 보였음. `python scripts/unify-f2-helmet.py <저장소> apply`로 7방향의 크림색 픽셀을 정면 헬멧의 색 단계로 맞춤(먼저 `preview`로 확인). 그다음 `build-f2-v2.py`, `build-atlases.py`.

## 다시 만들기

`frames/`는 용량(17MB) 때문에 git에 올리지 않는다. 프레임이 있는 곳에서 `python scripts/build-f2-v2.py`를 실행하면 시트, `manifest.json`, `game-clips.json`의 F2 항목이 다시 만들어진다. 그다음 `python scripts/build-atlases.py`를 실행한다. `scripts/build-game-clips.mjs`는 융합 배치 파일이 저장소에 없어서 F2에는 쓸 수 없다.
