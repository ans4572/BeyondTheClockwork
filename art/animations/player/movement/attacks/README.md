# F2 · PixelLab 긴 렌치 공격 3타 · 8방향

왼팔 부분 수정 반영: 남향 1타 10프레임·2타 9프레임, 총 19프레임에 빈 왼팔을 복원했다. PixelLab Pro Flash로 두 대표 팔 영역만 마스킹해 보정한 뒤, 같은 팔 픽셀을 PixelLab pixelart_workbench에서 인접 프레임의 자세에 맞춰 배치했다. 기존 불투명 픽셀과 왼팔 ROI 밖 픽셀은 전부 보존했다. 나머지 22클립의 PNG/GIF와 전체 프레임 시간도 변경 전과 일치한다. `arm-repair-v1/verification.json`과 `comparison.gif`에 검증·전후 비교를 기록했다. 원본 408장은 보존하고 보정 PNG 19장을 별도로 연결했다. 팔 보정에만 추가 생성 12회를 사용했다. 이 수정에서 전체 애니메이션을 다시 생성하지 않았다.

초기 공격 제작 기록: 3타 × 8방향 = 24클립. 선택된 실제 생성 384프레임(1타 128·2타 96·3타 160)과 입력 24장, 총 원본 408장이다. 1타는 입력 포함 17프레임, 2타 13프레임, 3타 21프레임이다. 빈 프레임·투명도·GIF 길이·프레임 경계를 확인했다. 초기 제작과 당시 보정까지 구독 생성 62회를 사용했으며 당시 잔량은 1,861회였다. 이후 위의 왼팔 보정에 12회를 추가 사용하여 잔량은 1,849회다. 북서 3타의 머리 위 준비 실루엣과 북동 2타의 중간 머리 측면은 후속 보강 메모를 남겼다.

이동 애니메이션과 같은 F2의 PixelLab 8방향 원본을 기준으로 PixMiniMax에서 실제 프레임을 생성했다. 96×96 원본에 사방 48px의 투명 여백을 붙인 192×192 입력을 사용한다. 캐릭터 픽셀을 확대·재샘플링하지 않고, 큰 렌치 궤적과 머리 위 준비 동작이 들어갈 공간을 확보했다. 같은 대기 원본을 시작/종료 목표로 지정했다.

## 동작과 손 규칙

- 1타: 오른손 렌치를 몸의 오른쪽으로 준비하여 왼쪽으로 휘두르는 횡타.
- 2타: 렌치를 몸의 왼쪽으로 천천히 준비한 뒤 오른쪽으로 한 번 휘두르는 반대 횡타. 준비 동작에 공격 궤적이 중복되는 첫 시도는 재생성했다.
- 3타: 머리 위로 같은 렌치를 들어 올려 전방 바닥으로 내려찍기. 이 타격에서만 왼손이 같은 손잡이를 보조할 수 있다. 렌치는 한 개이며 기본 그립은 해부학적 오른손이다.

북쪽 1타의 과한 측면 회전은 후면 유지 지시를 강화한 별도 생성본을 선택했다. 2타의 중복 준비 궤적은 한 번만 공격하도록 재생성했고, 그중 북쪽 계열과 남동의 큰 효과 덩어리는 효과 없이 렌치 동작이 보이도록 추가 재생성했다. 나머지 방향도 프레임에서 그립·궤적·종료 자세를 검토한다. AI 출력은 최종 게임용 스프라이트 승인을 의미하지 않는다. 본편에 맞춘 접지·이동 보정·공격별 타격 프레임과 콤보 취소/전환 구간 정리는 후속 작업이다.

## 재생과 시간

`index.html`은 3타 연속/각 타격 단독, 8방향 동시 검토, 속도·프레임 탐색·반복을 제공한다. 기본 검토 길이는 800/850/1100ms다. 기획 속도는 기존 combat JSON의 280/320/480ms를 참고하여 같은 프레임 전체를 압축 재생하는 비교 옵션이며, 실제 AI 타격 프레임을 피해 판정에 동기화했다는 뜻이 아니다. GIF는 마지막 프레임을 추가 300ms 유지한다.

시트와 원본은 입력 프레임 1장을 포함한다. `generatedFrameCount`는 실제 생성 수, `frameCount`는 입력 포함 원본 수다. 좌우 반전이나 합성 중간 프레임을 사용하지 않는다. 실제 피해·성장·판정 데이터는 변경하지 않았으며 본편에는 적용하지 않았다.

## 파일과 재현

`manifest.json`은 선택된 24클립·프레임 시간·원본 경로·작업 ID, `production.json`은 제작 시도와 선택 상태, `prompts.json`은 초기 지시, `submissions-*.json`은 실제 제출 설명·시드·픽셀랩 응답이다. 최종 선택본 재현에는 보정 지시가 반영된 `selected-prompts.json`을 사용한다. `clips/*/frames/`는 받은 원본 그대로이며, 왼팔 수정 PNG는 `arm-repair-v1/frames/`에 별도로 보존한다. 매니페스트의 `sourceFiles`는 원본, `files`는 수정 프레임을 포함한 재생 순서다. `sheet.png`는 4열 배열, `preview.gif`는 그 재생본이다. `combo-8-directions.gif`는 방향별 3타 연결, `overview.gif`는 24클립 비교다. ZIP에는 선택된 결과·수정 내역·수정 전 원본을 담는다.

`scripts/import-f2-pixellab-attacks.mjs`는 완료된 원본을 다운로드·내보내고 아직 처리 중인 작업은 pending으로 남긴다. 재제작본은 submission의 더 높은 priority를 선택하므로 생성 중인 교체본이 있으면 완료로 표시하지 않는다. `scripts/finalize-f2-pixellab-attacks.mjs`는 모든 방향과 원본 규격을 재확인하고 기록·패키지·SHA256 목록을 만든다. 네트워크가 허용된 환경에서 실행하며 기존 원본은 다시 다운로드하지 않는다. 검토 HTML은 프로젝트 서버로 연다.
