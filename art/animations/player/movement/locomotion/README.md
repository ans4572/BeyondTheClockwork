# F2 · PixelLab 대기·걷기·달리기 8방향

24클립 제작 완료: 반복용 실제 생성 프레임 256장(대기 64·걷기 96·달리기 96), 입력 24장을 포함한 선택 원본 280장. 모두 투명 PNG이며 시트·GIF·JSON·전체 비교 화면을 제공한다. 서쪽 대기/걷기의 렌치 가시성과 북쪽 달리기의 후면 오류는 별도 재생성본으로 교체했다. 첫 시도와 보정을 포함해 구독 생성 75회를 사용했으며 잔량은 1,923회다.

F2 원본을 기반으로 PixelLab Pixen에서 긴 렌치를 반영한 96×96 기준 이미지를 만들고, V3로 8방향 캐릭터를 생성했다. 최종 이동 클립은 PixelLab PixMiniMax가 방향별로 생성한다. 좌우 반전이나 로컬 관절 리그로 대체하지 않는다. 전투·성장 JSON과 본편은 변경하지 않는다.

## 선택된 결과와 파일

최종 범위는 대기·걷기·달리기 × 8방향 = 24클립이다. 최종 상태와 실제 프레임 수는 `manifest.json`과 `validation.json`을 기준으로 확인한다. `index.html`에서 동작·방향·속도·프레임 탐색, 8방향 동시 재생을 제공한다. `overview.gif`는 전체 비교이며 ZIP은 선택된 클립만 포함한다.

- 대기: 생성 8프레임, 1,600ms 루프. 발을 고정한 작은 무게 이동과 스카프 움직임.
- 걷기: 생성 12프레임, 720ms 루프. 지지·밀어내기·회수, 빈 왼팔의 반대 움직임.
- 달리기: 생성 12프레임, 480ms 루프. 더 큰 보폭과 무릎 회수, 짧은 체공, 전경사.
- 각 작업의 입력 프레임 1장은 원본 폴더에 보존하지만 반복 재생에서는 제외한다. 반복마다 정지 기준 자세가 끼어드는 현상을 피하기 위한 선택이다.
- 원본 프레임은 `clips/*/frames/`의 120×120 또는 124×124 PNG다. 시트·GIF의 셀은 128×128로 투명 여백만 추가했다. 픽셀 크기를 바꾸거나 새 중간 프레임을 합성하지 않는다.
- `sourceFiles`는 입력 포함 원본, `files`는 반복 재생에 쓰는 생성 프레임 순서다. 시트는 4열이며 프레임 시간은 별도 JSON이다.

## 품질 검토와 재제작

기본 템플릿으로 먼저 제작했으나 여러 방향에서 긴 렌치를 누락하여 최종 결과로 채택하지 않았다. PixMiniMax에서는 오른손 렌치 유지·빈 왼손·제자리 동작·방향 고정을 명시했다. 서쪽 기준 이미지는 멀리 있는 오른팔의 그립과 렌치를 보이도록 PixelLab로 보정하고, 대기·걷기 해당 방향도 다시 생성했다. 선택된 그룹은 `production.json`의 preferredGroups와 overrideGroups에 기록한다. 기존 리그와 첫 시도는 보존한다.

자동 검사는 투명도, 빈 프레임, 프레임 규격, GIF 프레임 수·길이, 시트 배열과 출력을 확인한다. 이는 외형이나 발 접지를 자동 승인하는 검사가 아니다. 출력은 아트 검토본이며, 본편 적용 전 지면 기준점·발 미끄러짐·루프 경계·방향 전환과 렌치 그립을 실제 이동 속도에 맞춰 검토해야 한다. 카메라 이동이나 엔진 이동값은 포함하지 않는다.

## 출처와 재현

`production.json`에 캐릭터 ID·선택 그룹·작업 기록을, `*-submission.txt`에 실제 픽셀랩 응답과 동작 설명을 보존한다. `character-complete.txt`는 최종 다운로드 URL·프레임 수의 원본 응답이다. `scripts/import-f2-pixellab-movement.mjs --source=character-complete.txt`가 선택된 그룹의 원본 다운로드·시트·GIF·검증·전체 미리보기를 만든다. 네트워크가 허용된 실행 환경이 필요하며, 이미 받은 프레임은 다시 다운로드하지 않는다. `scripts/package-f2-pixellab-movement.mjs`가 24클립과 원본 PNG 규격을 재확인하고 ZIP·SHA256 목록을 만든다. HTML 검토 화면은 프로젝트 서버로 열어야 한다.

서쪽 대기·걷기·달리기와 북서쪽 걷기·달리기는 긴 청록 렌치와 검은 장갑으로 고친 기준 이미지로 다시 만든 클립입니다(`scripts/import-f2-revised-locomotion.mjs`). 이전 클립 폴더는 비교용으로 남아 있고 게임에서는 쓰지 않습니다.
