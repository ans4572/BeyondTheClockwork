# 기본 기술 1번째 4종 · PixelLab 8방향

[재생 화면](index.html) · [클립 데이터](manifest.json) · [32클립 패키지](primary-skills-pixellab.zip)

과열 휘두르기·서리 볼트·도전 스패너·압축 돌진, 각 8방향의 실제 PixelLab PixMiniMax와 Skeleton V3 프레임입니다. 방향별 프레임 수와 원본 크기는 manifest.json에 기록하며, 투명 PNG 시트·GIF를 제공합니다. 좌우 반전이나 보간 프레임을 사용하지 않습니다.

서리 볼트는 빈 왼손에서 3발로 시전하며 오른손은 긴 렌치를 유지합니다. 나머지 3종은 오른손 렌치를 사용합니다. 후면은 PixelLab Skeleton V3의 3D 관절 가이드로 등 방향을 유지하도록 별도 보강했고, 초안 돌진의 몸체 잔상과 잘못된 방향 초안은 최종 목록에서 제외합니다.

양팔·손·양다리의 연결, 불투명한 몸체 유지, 준비·방출·복귀 동작을 시트와 개별 프레임으로 검토했습니다. 자연스러운 관절 겹침은 방향별로 존재합니다. AI 픽셀 외형은 일부 프레임에서 세부 차이가 있으므로 본편 크기에서의 최종 타이밍·외형 조정은 별도 단계입니다.

재생은 아트 검토 속도입니다. 게임의 피해·재사용·서리 3발·돌진 거리와 0.2초 수치는 변경하지 않으며 root 이동도 이미지에 굽지 않습니다. 제작 입력과 요청·선택 기록은 production.json, 신체 검토 기록은 qa-review.json에 있습니다.
