# 융합 스킬 6종 · PixelLab 8방향

[재생 화면](index.html) · [48클립 JSON](manifest.json) · [패키지](fusion-eight-directions.zip)

기존 남동 대표 6클립의 PNG·GIF·프레임 JSON 104개는 해시가 같은 원본으로 유지했습니다. 나머지 7방향씩 총 42클립을 추가했습니다.

새 방향은 기존 융합 원화에서 만든 PixelLab 8방향 캐릭터를 기준으로 3종 시전 동작(21개 방향 클립, 252프레임)을 Skeleton V3로 생성했습니다. 원화에서 추출한 융합 효과 6종은 PixMiniMax로 생성했습니다. 이 몸체와 VFX를 방향별 위치·궤적으로 조합합니다. 42개의 독립 전신 AI 생성 작업이라는 의미는 아닙니다.

오른손은 긴 렌치를 유지하고 빈 왼손으로 시전합니다. 양팔·손·양다리, 준비·시전·복귀와 후면 방향을 전체 몸체 프레임에서 검토했습니다. 이펙트 합성 후에도 몸체 불투명 픽셀 3,759,967개가 그대로임을 출력 PNG에서 검증했습니다. 관절의 정상적인 가림은 존재합니다. 검토 화면의 몸체 확대·이펙트만 보기로 분리 확인할 수 있습니다.

증기 파쇄는 불·얼음·증기 파열, 전호 용광로는 금빛 방전과 화염, 화염 회오리는 전방 이동 나선, 자성 빙쇄는 얼음 턱 압착과 보라 방전, 빙풍 절단은 왼손에서 함께 나가는 곡선 세로 X, 폭뢰 부유구는 고정 구체의 전기·바람 파열을 유지합니다. 빙풍 절단의 분리 칼날·회색 매트 생성 프레임은 재생에서 제외했고, 증기 중심부의 인물 잔여는 PixelLab 정밀 편집으로 제거했습니다.

기존 대표 합성본과 신규 분리본 사이에는 일부 외형·시전 시점 차이가 있습니다. 이 자료는 아트 검토용이며 게임의 피해·타격 시점·범위·재사용·축전 JSON은 변경하지 않았습니다. 신규 합성 캔버스는 여백을 포함한 512픽셀이고 원본 픽셀을 재샘플링하거나 캐릭터를 좌우 반전하지 않습니다.

원본 몸체·VFX는 expansion/bodies와 expansion/effects, 방향별 출력은 expansion/composites, 위치·시간 정의는 expansion/layout.json, 검토 기록은 expansion/qa-review.json과 expansion/validation.json에 있습니다.
