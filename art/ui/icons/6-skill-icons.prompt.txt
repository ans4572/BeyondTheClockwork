Redraw the 14 SKILL and FUSION icons of Beyond the Clockwork, a cute wind-up toy-town roguelite, so they match the new pixel icon set. They sit in the skill bar next to the basic attack and dodge icons, on the reward cards and in the codex, shown at 36-56 screen pixels.

WHY A REDRAW
The current icons (art\ui\skill-icons\*.png) have soft, anti-aliased edges and no outline, so they look blurry beside the new crisp icons. Keep what each one SHOWS (its subject, pose and element colour) but redraw it in the new style.

STYLE REFERENCES (match these exactly)
- art\ui\icons\action-wrench-v1.png and art\ui\icons\action-dodge-v3.png: the icons in the same skill bar.
- art\ui\icons\reward-wrench-damage-v2.png, art\ui\icons\reward-status-damage-v1.png, art\ui\icons\coin-v1.png: the same pass.
Match their crisp pixel clusters, 1 grid pixel dark navy outline (#2b3345), top-left light, saturation and pixel density.
Palette: navy ink outline (#2b3345), polished brass and gold, warm cream, plus the element colours: fire #ef8a61 / #e8742f, ice #79cbd1 / #66bde8, lightning #e9bd59 / #ffe086, wind #89bea0 / #8fd8b0. F2's wrench is teal #5ca99a when a wrench appears.

DRAW EACH ICON
- Pixel art on a 48x48 pixel grid, then output at 384x384 with every grid pixel as an exact 8x8 block (no smoothing, no anti-aliasing, no half pixels), so it scales down to 48x48 perfectly.
- TRANSPARENT background (PNG with alpha), one centred subject, 2 grid pixels of empty margin, a 1 grid pixel dark navy outline round the silhouette.
- Must read at 28 pixels: one bold silhouette, at most 8-10 colours, no text.
- The element colour dominates each skill; fusions show both of their elements.
- Every icon keeps a clearly different silhouette from the others.
