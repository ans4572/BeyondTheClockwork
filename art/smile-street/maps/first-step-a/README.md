# 첫 걸음 광장 A · 게임 적용 맵

13구간 여정의 첫 전투방 `stop-02`에 쓰는 맵입니다. 배경은 [승인된 시안](../../map-concepts/first-step/room-a-multiway-v1.png)을 1120×640으로 줄인 그림입니다.

이동 영역, 가림 영역, 시작 위치는 `src/data/maps.json`에 있습니다. 좌표는 이 배경 위에서 직접 읽은 화면 좌표이며 1유닛은 40픽셀입니다. `map-concepts/navigation-proposals.json`의 블록아웃은 대각선 좌표라서 사용하지 않았습니다.

- `walkable`: 캐릭터의 발이 움직일 수 있는 바닥 다각형입니다.
- `occluders`: 캐릭터가 뒤로 지나가는 물체입니다. `baseY`보다 위쪽에 발이 있는 캐릭터 위로 같은 배경의 해당 영역을 다시 그립니다.
- `spawn`, `enemySpawns`: 방에 들어올 때의 위치입니다.

새 방을 추가할 때는 배경을 같은 크기로 넣고 `maps.json`에 방 ID로 항목을 추가합니다. 항목이 없는 방은 기존 코드 배경과 사각 전장을 씁니다.

출구는 아직 걸어서 나가지 않습니다. 기존처럼 전투가 끝나면 보상을 고른 뒤 다음 방으로 넘어갑니다. 그림의 북쪽과 동쪽 출구까지 걸어갈 수는 있습니다.
