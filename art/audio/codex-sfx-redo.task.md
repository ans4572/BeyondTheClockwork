저장소 루트(`Beyond the Clockwork`) 기준 경로입니다. **새 후보 레시피와 후보 듣기 페이지만** 만듭니다. 게임이 쓰는 소리(`src/audio/sfx.js`의 `SFX` 표에서 고른 후보와 음량)는 바꾸지 않습니다. 사용자가 후보를 고르면 Claude가 게임에 연결합니다. 게임 규칙·데이터(`src/engine/`, `src/data/`), 그림, 배경음악, 기존 테스트는 건드리지 않습니다. 커밋과 푸시는 하지 않습니다.

## 배경

- 이 게임의 효과음은 녹음 파일이 아니라 Web Audio 코드로 합성합니다. 레시피 하나는 `(audio, out) => { ... }` 함수이고, `out`(게인 노드)에 그립니다.
- 2026-11-09 오전에 효과음 전체를 다듬었습니다(`art/audio/codex-sfx-polish.task.md`): 공용 짧은 울림과 컴프레서(`SoundBank.bus`), 어택 최소값과 반복 음 높이 변주(`src/audio/synthesis.js`).
- 사용자가 아래 25개는 **다듬은 것도 기존 것도 아닌, 완전히 새로운 소리**를 원합니다. 지금 소리를 고쳐 쓰지 말고, 새로 설계한 레시피로 만듭니다.

## 게임의 결 (모든 후보 공통)

- **세계:** 태엽 장난감 마을과 장난감 공장. 귀엽고 손에 잡히는 장난감 소리(나무, 놋쇠, 태엽, 용수철, 고무, 종이, 천, 유리, 물, 증기)이고, 공포나 현실적인 무기 소리가 아닙니다. 배경음악은 피아노 중심 어쿠스틱 판타지 RPG 곡입니다.
- **느낌:** 톡톡 튀거나 딸깍거리지 않고, 둥글고 손맛 있게. 같은 소리를 50번 들어도 귀가 피곤하지 않아야 합니다(특히 `hit`, `tell`, `block`, `mirrorTurn`).
- **역할이 들리게:** 플레이어 타격(`hit`, `heavy`)은 시원하고 무게가 있게, 적의 공격과 예고(`tell`, 2장 적, 브라스)는 '피해야 한다'는 신호로 분명하게, 실패(`moldNo`)는 짜증 나지 않게 짧고 귀엽게.
- **겹침:** 전투 중에는 렌치 적중, 몹 공격, 배경음악이 함께 납니다. 중저역을 너무 채우지 않고, 소리마다 주된 음역이 겹치지 않게 나눕니다(예: `tell`은 고음역의 짧은 신호, `hit`은 중음역의 몸통).

## 후보 3개는 서로 다른 방향으로

각 소리마다 후보 3개를 만듭니다. 셋이 같은 소리의 변형이 아니라 **재료나 발상이 다른 세 방향**이어야 합니다. 예:

- `hit`: ① 나무 망치로 장난감 몸통을 치는 '퍽'(나무 + 낮은 몸통) ② 놋쇠 렌치가 태엽 장치에 맞는 '탱'(짧은 금속 울림 + 둥근 몸통) ③ 고무 장난감을 때리는 '뽁'(탄력 있는 피치 하강)
- `tell`: ① 작은 오르골 한 음 ② 나무 딸랑이 두 번 ③ 태엽이 '찌릿' 감기는 짧은 상승음
- `summon`: ① 오르골 상자가 열리며 올라가는 세 음과 착지 ② 장난감 상자 뚜껑 '덜컥'과 용수철 ③ 공장 작업 종 '땡'과 컨베이어가 움직이는 소리
- `hydroJet`: ① 소방 호스처럼 굵은 물줄기(중저역 쉬이익 + 물 떨림) ② 물총 장난감처럼 가볍고 밝은 분사 ③ 펌프질 맥동이 있는 물줄기

나머지 소리도 같은 식으로 직접 세 방향을 정하고, 후보 이름(한국어, 짧게)에 그 방향이 드러나게 짓습니다(예: `'나무 망치 퍽'`).

## 만들 것

1. **`src/audio/redo-sound.js` (새 파일):** `export const REDO_CANDIDATES = { hit: [['이름', (a, o) => { ... }], [...], [...]], heavy: [...], ... }`. 키는 위 표의 `SFX` 이름 그대로(25개), 값은 후보 3개.
   - 공용 도구는 `src/audio/synthesis.js`(`attackTime`, `pitch`, `grains`)와 `src/audio/water-sound.js`의 함수(`noise`, `tone`, `band`, `whoosh`, `ring` 등)를 가져다 씁니다. 필요한 새 도구는 이 파일 안에 둡니다.
   - 음 높이는 `pitch(a)`를 곱해 반복 변주가 걸리게 하고, 어택은 `attackTime(a, …)`을 거쳐 최소값이 지켜지게 합니다.
2. **`SoundBank.play`에 선택 옵션 하나 추가 (`src/audio/sfx.js`):** `play(audio, name, gainScale, { recipe, volume })`처럼 레시피와 음량을 넘기면 `SFX` 표 대신 그것으로 재생하되, 나머지(공용 울림·컴프레서 버스, 반복 변주, `live`/`stop`)는 게임과 똑같이 거칩니다. 옵션이 없을 때 동작은 지금과 완전히 같아야 합니다(테스트로 확인).
3. **`sound-redo.html` (저장소 루트, 새 파일):** 후보 듣기 페이지.
   - 소리마다 한 줄: 번호, 이름, 언제 나는지, 버튼 4개 **[지금] [후보 1] [후보 2] [후보 3]**. 버튼에 후보 이름을 함께 적습니다.
   - 모든 버튼은 위 2번 옵션으로 게임과 같은 처리(공용 버스)를 거쳐 재생합니다.
   - **음량 맞춤:** 각 후보의 음량은 '지금' 소리와 가장 시끄러운 50ms RMS가 ±1.5dB 안이 되게 정해 페이지에 숫자로 적어 둡니다(OfflineAudioContext로 측정, 난수 시드 몇 개의 중앙값). 이 값이 그대로 게임 음량이 됩니다.
   - **연타 버튼:** `hit`(0.15초 × 8), `heavy`(0.35초 × 4), `tell`(0.12초 간격 3마리 겹침 × 3), `block`(0.2초 × 6), `boss-mirrorTurn`(0.45초 × 6)은 [지금]과 후보마다 연타로도 들을 수 있게 합니다.
   - `hydroJet`은 버튼을 누르고 있는 동안 나고 떼면 0.1초 안에 멈추게 합니다(게임의 `SoundBank.stop`과 같은 방식).
   - **휴대폰에서 들을 수 있게:** 버튼은 엄지로 누르기 좋은 크기(높이 44px 이상), 한 줄 레이아웃, 첫 탭에서 소리 켜기(iOS Safari 포함). 페이지가 불러오는 것은 `src/audio/*.js` 모듈과 `art/fonts/` 글꼴뿐이어야 합니다(Claude가 이 페이지를 휴대폰용 한 파일로 묶을 때 필요).
   - 맨 위에 듣는 방법 세 줄과, 고른 결과를 `hit 2, heavy 1, …`처럼 적어 보내 달라는 안내.

## 지켜야 할 것

1. **게임은 그대로:** `SFX` 표의 고른 후보와 음량, `coded.js`·`elements.js`·`water-sound.js`·`boss2-sound.js`·`mob2-sound.js`의 기존 레시피, 엔진이 소리를 내는 순간은 바꾸지 않습니다. 게임에서 들리는 소리는 이 작업 전후로 같아야 합니다.
2. **새 소리:** 지금 레시피를 복사해 수치만 바꾼 후보는 안 됩니다. 위 표의 '지금 소리'와 듣고 바로 구별되어야 합니다.
3. **부드럽게:** 어택 최소 4ms(타격 `hit`·`heavy`·`block`·`burst`), 그 밖에는 6ms 이상. 6kHz 위는 깎거나 몸통 아래에 깔리게. 사각파·톱니파는 저역 통과(2~3kHz)를 거치거나 쓰지 않습니다.
4. **녹음 파일·외부 라이브러리 금지:** Web Audio 노드만 씁니다. 새 패키지를 설치하지 않습니다.
5. **가볍게:** 소리 하나가 만드는 오디오 노드는 공용 버스를 포함해 40개 이하. 짧은 알갱이가 많으면 `grains`로 버퍼 하나에 굽습니다.
6. **모바일 안전:** iOS Safari에서 동작하는 API만. `OfflineAudioContext` 길이는 정수 샘플, `AudioParam` 값은 유한한 숫자.
7. **테스트:** `npm test`가 전부 통과해야 합니다(지금 403개). 기존 테스트 파일은 고치지 않습니다. 2번 옵션이 없을 때 동작이 같다는 테스트는 새 파일로 추가해도 됩니다.

## 확인 방법

1. 개발 서버(실행 중인 것 사용)에서 `sound-redo.html`을 열어 25줄 × 4버튼과 연타 버튼을 모두 눌러 봅니다. 콘솔 오류가 없어야 합니다.
2. 측정 스크립트를 임시 폴더에 만들어(저장소에 넣지 않음) 후보마다 다음을 표로 남깁니다: 가장 시끄러운 50ms RMS(지금 소리와 차이), 크레스트(피크 ÷ RMS), 4kHz 이상 에너지 비율, 어택 시간, 길이, 노드 수.
3. `sound-redo.html`과 `sounds.html`을 열어 둔 채 `npm test`를 돌립니다.
