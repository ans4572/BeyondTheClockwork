# Codex 작업: 3장 중앙시계탑 전투 방 B 맵 6장 생성 + 같은 작업에서 2배 업스케일

저장소 루트(`Beyond the Clockwork`) 기준 경로입니다. 이미지 생성과 이어 붙이기만 합니다. 코드·데이터(`src/`, `test/`, `worker/`, `scripts/`)와 기존 그림 파일은 건드리지 않고, 커밋·푸시도 하지 않습니다. 마스크·맵 데이터·게임 연결은 이쪽에서 합니다.

## 왜 만드나

1·2장은 일반 전투 방마다 그림이 A·B 두 장이고, 원정마다 둘 중 하나가 골라집니다. 3장은 A만 있어서, 일반 방 6곳(01·02·03·06·07·08)에 B를 만듭니다. 보스 방(04·09)과 상점(05)은 A 하나로 둡니다.

B는 **같은 방의 다른 쪽 모습**입니다. 바닥 재질·색·빛·시간대·물체 크기·빈 바닥 크기는 A와 같고, 벽 구성·큰 가구·앞쪽 풍경만 다릅니다. 출구는 A와 같은 가장자리, 같은 높이에 있습니다(게임이 들어오고 나가는 방향을 A와 똑같이 씁니다).

## 입력 이미지

- 입력 이미지 1 = `art/chapters/1-smile-street/maps/01-first-step-plaza/background-compact-v1.png` (1장 전투 방, 화풍·카메라·물체 크기 기준, 1536×1024)
- 입력 이미지 2 = `art/scenes/clocktower-summit/background-v2.png` (시계탑 재료 기준)
- 입력 이미지 3 = 그 방의 A (아래 표의 'A 그림', 게임 크기 원본)

프롬프트가 "Input image 1/2/3"으로 부르므로, 이 순서 그대로 넣습니다.

## 방마다 순서 (한 방을 끝까지 마치고 다음 방으로)

파일이 이미 있으면 덮어쓰지 말고 `-v2`, `-2`처럼 새 이름으로 저장합니다.

### 1단계: B 그림 생성

1. 프롬프트 파일 내용을 **그대로** 이미지 생성 프롬프트로 씁니다(요약·번역·수정 금지). 입력 이미지는 위 순서(1·2·3)로 넣습니다.
2. 생성된 크기 그대로 `<방>-b/background-v1.png`로 저장합니다.
3. 아래 '1단계 확인'을 통과할 때까지 같은 프롬프트로 다시 생성합니다(최대 3번, 그래도 안 되면 가장 나은 것을 쓰고 보고).

### 2단계: 게임 크기 원본

`background-v1.png`를 표의 '게임 크기'로 Lanczos 축소(이미 그 크기면 그대로 복사)해 **무손실 PNG** `<방>-b/background-v1-1x.png`로 저장합니다. 비율을 바꾸거나 자르지 않습니다. 3단계의 입력이고, 마스크도 이 그림 위에 그립니다.

### 3단계: 같은 배치 그대로 2배 해상도로 다시 그리기

**방법은 3장 A 맵 업스케일과 완전히 같습니다.** `art/chapters/upscale-2x-batch.task.md`의 '맵마다 순서'(3×3 조각, 조각 크기 공식, 겹침, 선형 페더 섞기, 조각별 색 맞춤), '저장 전 확인'을 그대로 따르고, `art/chapters/upscale-2x-ch2-rest.task.md`의 '앞 작업에서 배운 것'(COLOUR 문단 덧붙이기, 흰 면적 기준, 글자 금지, 바닥만 있는 칸의 거짓 경보)도 그대로 지킵니다. 3장 A 맵 때 쓴 프롬프트와 스크립트(`art/chapters/3-clock-tower/maps/upscale-work/ch3-batch.py`, 각 A 폴더의 `upscale-work/`)를 다시 씁니다.

- 입력: `<방>-b/background-v1-1x.png` (1단계의 큰 PNG가 아님)
- 작업 파일: `<방>-b/upscale-work/` (git에서 빠져 있음)
- 결과: `<방>-b/background-v2x.png`, 입력의 **정확히 2배** 크기
- 비교 그림: `<방>-b/upscale-work/compare.png` (바닥 한 곳, 물체가 많은 곳 한 곳)
- 방마다 지킬 점: 시계 문자판은 눈금만(숫자 금지). 청록 신호선·구체·케이블 빛을 넓히거나 밝히지 않음. 창밖 마을을 더 크게·가깝게 그리지 않음. 06은 세로로 긴 맵.

## 1단계 확인 (B 그림 한 장씩)

**A와 같은 방인가**
- 입력 이미지 1·3과 같은 픽셀 아트 화풍, 같은 쿼터뷰 카메라, 같은 물체 크기다. 입력 이미지 2의 그림체나 정면 카메라를 따라가지 않았다.
- `background-v1-1x.png`와 A 그림(입력 3)을 50% 겹쳐 봤을 때 바닥 타일·문·계단 한 칸의 크기가 비슷하다(B가 확대된 것처럼 보이지 않음). 겹친 그림을 `<방>-b/upscale-work/overlay-a.png`로 남깁니다.
- 바닥 재질·색, 시간대 빛, 색 구성이 A와 같다(01~03 밤, 06·07 깊은 밤, 08 새벽 전).

**A와 다른 쪽 모습인가**
- A의 벽·큰 가구·앞쪽 풍경을 그대로 베끼지 않았다. 프롬프트 ROOM IDENTITY의 WALL·FOREGROUND대로다.

**싸울 수 있는 방인가**
- 출구가 정확히 2개이고, 가장자리와 높이가 프롬프트의 EXITS(= A와 같은 자리)와 같다.
- 가운데 빈 바닥의 크기가 A와 비슷하고, 바닥 위에 작은 물체·케이블·잔해가 없다.
- 탑 안의 한 층이다: 그림 가장자리·모서리에 하늘·구름·빈 공간이 없다(창 너머만 예외). 공중에 뜬 둥근 판, 앞쪽 둥근 난간, 아래 가운데 톱니 아치가 없다.
- 시계 문자판에 숫자·글자가 없다. 사람·인형·캐릭터·글자·숫자·UI가 없다. 청록은 가는 선과 작은 빛뿐이다.

3. 3단계: 조각 수와 (0, 0)이 아닌 조각(있으면 위치와 이유), 전체 평균 절대차, 채도·밝기 차, 흰 면적(원본 % / 결과 %), 다시 생성한 조각과 이유, `compare.png` 경로.
