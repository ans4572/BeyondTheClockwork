# 벨가드 공격 동작의 이펙트 목록 (2026-11-16)

PixelLab이 동작 안에 그려 넣은 이펙트를 방향·프레임별로 정리했다. 프레임 번호는 0이 기준 그림(서 있는 자세), 1~8이 동작이다. 크기: 대 = 몸만 하거나 더 큼, 중 = 칼날만 함, 소 = 몇 픽셀의 점·불티. 아직 고치지 않았다.

## 내려찍기 (attack-slam) — 칼이 바닥에 닿는 순간의 충격

| 방향 | 프레임 | 이펙트 | 색 | 크기 |
|---|---|---|---|---|
| 남 | 5 / 6 / 7 | 별 모양 폭발 / 불티 줄기 / 점 | 노랑+흰색 / 주황·빨강+노랑 / 흰색 | 대 / 중 / 소 |
| 남동 | 4 / 5 / 6 | 작은 폭발 / 폭발 / 불티 | 노랑 / 노랑 / 주황·빨강 | 중 / 중 / 중 |
| 동 | 3 | 칼끝 불꽃 | 흰색 | 소 |
| 북동 | 6 / 7 | 칼끝 불꽃 / 점 | 흰색+노랑 / 흰색 | 소 / 소 |
| 북 | 6 / 7 | 폭발 / 점 | 노랑 / 노랑 | 중 / 소 |
| 북서 | 5 / 6 | 칼끝 불꽃 / 폭발 | 흰색 / 노랑 | 소 / 대 |
| 서 | 5 / 6 | 세로로 긴 폭발 / 불티 | 흰색+노랑 / 노랑+주황 | 대 / 중 |
| 남서 | 7 | 폭발 | 흰색+노랑 | 대 |

- 모든 방향에 무언가 있지만 크기가 제각각이다. 큰 폭발은 남·북서·서·남서, 동·북동은 작은 불꽃뿐이다.
- 나오는 순간도 4~7번째 프레임으로 다르다. 색은 대부분 노랑·흰색이고, 남·남동·서에는 주황·빨강 불티가 섞인다.

## 휘두르기 (attack-swing) — 칼이 지나가는 궤적

| 방향 | 프레임 | 이펙트 | 색 | 크기 |
|---|---|---|---|---|
| 남 | 2 | 초승달 궤적 | 흰색·베이지 | 대 |
| 남동 | 2 / 3 | 초승달 궤적 / 가는 꼬리 | 베이지 / 크림 | 대 / 중 |
| 동 | 1 / 2 / 3 | 궤적 시작 / 큰 궤적 / 가는 꼬리 | 하늘색+흰색 / 하늘색+흰색 / 흰색 | 중 / 대 / 중 |
| 북동 | 3 / 4 | 궤적+불꽃 / 가는 꼬리 | 흰색+노랑 / 크림 | 대 / 중 |
| 북 | 3 / 4 | 궤적 / 별 모양 불꽃 | 하늘색+흰색 / 주황 | 대 / 중 |
| 북서 | 3 / 4 | 궤적 / 별 모양 불꽃 | 크림 / 노랑·주황 | 대 / 중 |
| 서 | 4 | 칼 잔상(칼과 같은 회색·베이지) | 회색·베이지 | 대 |
| 남서 | 2 | 초승달 궤적 | 주황·노랑 | 대 |

- 궤적 색이 네 갈래로 갈린다: 흰색·베이지(남·남동), **하늘색(동·북)**, 크림(북동·북서), **주황(남서)**, 칼과 같은 회색 잔상(서).
- 북·북서에는 궤적 뒤에 별 모양 불꽃이 따로 붙는다.
- 궤적이 칼날과 붙어 있어 자동 지우기(strip-effects, 몸과 떨어진 조각만 지움)로는 지워지지 않는다.

## 검 꽂기 (plant) — 칼이 바닥에 박히는 순간

| 방향 | 프레임 | 이펙트 | 색 | 크기 |
|---|---|---|---|---|
| 남 | 3 / 4 / 5~8 | 큰 별 모양 폭발 / 불티+금 / 바닥 금 | 노랑+흰색 / 주황 / 검정 선 | 대 / 중 / 소 |
| 남동 | 1 / 2 / 3~8 | 칼끝 불꽃 / 칼끝 불꽃 / 바닥 금 | 흰색 / 흰색 / 검정 선 | 소 / 소 / 소 |
| 동 | 3~8 | 바닥 금 | 검정 선 | 소 |
| 북동 | 3 / 4 | 위로 솟는 폭발 / 금 | 노랑+흰색 / 검정 | 대 / 소 |
| 북 | 4 / 5 / 6~8 | **칼이 금빛으로 빛남** + 폭발 / 불티+금 / 금 | 노랑+흰색 / 노랑 / 검정 | 대 / 중 / 소 |
| 북서 | 2 / 3 / 4~8 | 위로 솟는 가시 폭발 / 폭발 / 금 | 노랑+흰색 / 노랑 / 검정 | 대 / 중 / 소 |
| 서 | 1~3 / 4 | 흰 돌가루·자갈 / 점 | 흰색·회색 | 중 / 소 |
| 남서 | 3~8 | 바닥 금(폭발 없음) | 검정 선 | 소 |

- 폭발이 있는 방향(남·북동·북·북서)과 없는 방향(남동·동·서·남서)이 반반이다. 서쪽만 폭발 대신 돌가루다.
- 북쪽은 칼 자체가 금빛으로 바뀌는 프레임이 있다.
- 바닥 금은 남서·동·남동은 처음부터, 나머지는 폭발 뒤에 생긴다.

## 고치는 방법 (정해지면 진행)

1. **모두 지우고 게임 코드가 같은 이펙트를 그림 ★추천:** 칼과 떨어진 불티·돌가루는 자동으로 지우고, 칼에 붙은 궤적·폭발·금빛은 그 프레임만 손질한다(앞뒤 프레임의 칼로 바꿔 끼움). 충격·궤적·바닥 금은 게임이 방향과 상관없이 같은 색·같은 순간에 그린다. PixelLab 비용 없음.
2. **어긋난 방향만 다시 생성:** 궤적이 하늘색·주황인 방향(휘두르기 동·북·남서)과 폭발이 큰 방향(검 꽂기 남·북동·북·북서)을 "이펙트 없이"로 다시 만든다. 약 10~15회. 다시 만들어도 이펙트가 또 나올 수 있다.
3. **그대로 두고 색만 맞춤:** 이펙트 픽셀을 한 가지 색(예: 크림·금색)으로 바꾼다. 크기와 나오는 순간이 다른 문제는 남는다.

## 처리 결과 (2026-11-16, 1번으로 진행)

`scripts/import-ch3-belgard.mjs`가 게임 그림(`art/animations/mobs/clock-tower/clips/belgard-*`, 56개)을 만들며 이펙트를 모두 뺀다.

- 그 방향의 서 있는 그림(회전 + 서 있기 9장)에 없는 색 중 이펙트 같은 색(흰색, 노랑, 주황·빨강, 하늘색, 크림, 거의 검정)은 지운다.
- 발 높이 아래 18줄(바닥 부근, 장화 자리 빼고)에서는 몸에 있는 색이라도 이펙트 같은 색이면 지운다. 검 꽂기만 바닥 금(어두운 회색)도 지운다. 다른 공격에 쓰면 바닥에 눕힌 칼날의 테두리까지 지워져서다.
- 그 뒤 몸과 떨어진 조각(불티, 돌가루)을 지운다(strip-effects).
- 칼과 같은 색으로 붙어 있는 궤적·금빛 칼은 그 프레임을 뺀다(`characters.json` drop): 휘두르기 남 2, 남동 2·3, 동 1·2, 북동 3·4, 북 3·4, 북서 3·4·5, 서 3·4, 남서 2 / 검 꽂기 남 3, 북 4, 북서 2, 서 2.
- 남은 것: 검 꽂기 남서·남동의 칼끝 아래 아주 작은 금 몇 픽셀(장화 옆이라 남김).
- 충격·궤적·바닥 금은 벨가드 패턴을 만들 때 게임 코드가 방향과 상관없이 같은 색·같은 순간에 그린다.

## 다시 고침 (2026-11-16, 사용자 지적: 시안 페이지에서 공격 때 검이 이상함)

첫 규칙이 바닥 근처의 흰색·어두운 회색을 지우다가 꽂힌 칼날 아래쪽(반사광·테두리)과 내려찍은 칼날의 반사광까지 지웠다. 바꾼 것:

- **두꺼운 부분 보호:** 그림을 2픽셀 깎아도 남는 두꺼운 부분(칼날, 장화)과 그 둘레 3픽셀은 바닥 규칙으로 지우지 않는다. 금·돌가루는 얇은 선과 부스러기라 지워진다. 장화 자리를 따로 빼던 규칙은 칼끝 아래 금까지 남겨서 없앴다.
- **덩어리로만:** 몸에 없는 이펙트 색은 12픽셀 이상 덩어리일 때만 지운다(칼 위의 새 반사광 몇 픽셀은 남김). 바닥 근처에서만 크기와 상관없이 지운다.
- **프레임 빼기 추가:** 내려찍기 남 5(폭발이 칼을 덮어 손잡이만 남은 프레임).
- 남은 것: 칼끝이 닿는 순간 칼끝에 붙은 몇 픽셀의 금·불티·돌가루(검 꽂기 남·남동·서·남서, 내려찍기 남동·동·북동·북서). 게임이 그 순간 칼끝에 충격 이펙트를 그려 덮는다.

## 내려찍기 칼이 닿기 직전 부분부분 사라짐 (2026-11-16, 사용자 지적)

원인: 원본에서 칼이 바닥에 닿는 순간의 폭발이 칼날 위에 덮어 그려져, 그 밑에 칼날이 없음(지우면 칼이 군데군데 빔). 색으로는 되살릴 수 없어 그 프레임을 뺌: 남 5, 남동 4·5, 북 6, 북서 6, 서 5, 남서 7. 칼을 든 자세에서 바로 칼이 닿은 자세로 넘어가고, 그 순간은 게임의 충격 이펙트가 채운다. 동작 전체 길이(1.3초)는 그대로라 남은 프레임이 조금씩 길어짐. 8방향 모두 칼날이 끝까지 온전함을 확대해 확인.

## 내려찍기 동·북동·북서 다시 만듦 (2026-11-16, 사용자 지적: 수직으로 꽂고 있음)

세 방향이 내려찍은 뒤 칼을 바닥에 수직으로 꽂고 서 있어 검 꽂기와 같아 보였다. PixelLab으로 다시 만들어(4회) 칼이 앞쪽 바닥에 비스듬히 눕게 함. 동쪽은 두 번 모두 오른쪽을 보는 3/4 각도로 나와 그대로 씀. 새 그림의 칼 궤적·폭발 프레임을 뺌: 동 2·3, 북동 3(북서는 이펙트 없음, 예전 북서 6 빼기는 없앰).

## 검 꽂기 두 손으로 통일 (2026-11-16, 사용자 요청)

남·남서만 두 손을 손잡이 위에 포갰고 나머지 6방향은 한 손이었다. 남동·동·북동·북·북서·서를 PixelLab으로 다시 만듦(8회: 6방향 + 북동 한 손 그대로, 북 정면으로 돌아섬 → 2방향 다시). 이제 7방향이 두 손을 포개 얹고, 북쪽은 끝까지 등을 보여 몸이 칼과 손을 가린다. 새 그림의 폭발·금빛 칼 프레임을 뺌: 남동 2, 동 2, 북동 3, 북서 3, 서 2(남 3은 그대로).
